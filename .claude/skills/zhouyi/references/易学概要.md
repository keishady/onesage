# 易学概要（来源、流变、方法、图）

提炼自《周易译注》的《前言》《〈周易〉一书的性质》《易图述略》《八宫卦图》《附注》。这些材料不直接用来占断，用于回答"《周易》是什么、怎么来的、各家怎么读、这些图是什么"一类问题，也用来判断一条说法有没有依据。

## 一、《周易》是怎么成的

1. **观物取象**：古人观察天地万物，抽出阴阳两画；三画叠成八卦（天地雷风水火山泽）；两两相叠成六十四卦，再配上卦爻辞。《系辞》："仰则观象于天，俯则观法于地……始作八卦，以通神明之德，以类万物之情。"
2. 卦象实例：晋（坤下离上，日出地上，进长）与明夷（离下坤上，日入地中，光明殒灭）互为反象。乾六爻都是阳爻，但初九"潜龙勿用"（蓄力）、上九"亢龙有悔"（过头）各自象征不同义理。
3. **作者与时代**（几种主流说法）：
   - 旧说：伏羲画卦；重卦者有伏羲、神农、夏禹、文王四说；卦辞文王作、爻辞周公作；《易传》孔子作（司马迁、班固、孔颖达）。
   - 北宋欧阳修起疑古：《系辞》《文言》《说卦》《序卦》《杂卦》非孔子作；清姚际恒、康有为推到极端。
   - 20世纪：顾颉刚等认为卦爻辞是周初作品；李镜池认为西周晚期编定；郭沫若认为春秋以后。较有影响的结论：**卦爻辞作于周初，《易传》作于春秋战国间，经传均是多人多时的集体成果**。
   - 考古：商周甲骨、金文中的"数字卦"说明筮法至少可上推到商代；《周礼》提到《连山》《归藏》《周易》三易。顾炎武认为重卦不始于文王。《系辞下》说"《易》之兴也，其当殷之末世，周之盛德邪"，是比较审慎的推测。
   - 本书倾向：远古已有类似筮书，殷末周初经过规范化改编（统一卦形、定卦序、充实卦爻辞），约公元前11世纪成《周易》。
4. **书名**："周"取周代之名（另有"周普"一说）；"易"本义是变易（取蜥蜴善变色，一说日月为易）。《易纬》说"易"含三义：简易、变易、不易。《周易》西文意译即"变化之书"。
5. **经传合编**：《易传》本来单行，汉代费直（或郑玄）把彖象文言分附于各卦，便于对照；此后通行。

## 二、十翼各篇是做什么的

| 篇 | 作用 |
|---|---|
| 文言 | 专释乾坤两卦（"文饰乾坤之言"） |
| 彖传 | 断一卦之主旨，释卦名卦辞，常指出卦主 |
| 大象 | 先讲上下卦象，再引出"君子以……"的行为准则 |
| 小象 | 解释每一爻吉凶的原因（387条，含用九用六） |
| 系辞传 | 易学总论：阴阳之理、观物取象、乾坤要旨、筮法，并解说十九条爻辞 |
| 说卦传 | 八卦取象的专论（乾健坤顺震动巽入坎陷离丽艮止兑说） |
| 序卦传 | 解释卦序，相邻两卦之间的承接逻辑；多是综或错 |
| 杂卦传 | 打散卦序，两两对举，一句话点明卦旨 |

## 三、《周易》是什么性质的书

- 争论：筮书还是哲学书？本书的结论：**以占筮为表，以哲学为里**。占筮只是它的用途之一，《系辞》说易有四用——"以言者尚其辞，以动者尚其变，以制器者尚其象，以卜筮者尚其占"。
- 理由（皮锡瑞、朱熹也承认）：若没有义理，占法无法让上层信服；孔子"以神道设教"，发明的是已有的义理。
- 哲学内容的四个层面：①六十四卦各喻一种处境的规律；②一卦之内六爻形成完整的发展过程（以师卦为例：初六师出以律→九二主帅中吉→六三舆尸败绩→六四左次退守→六五择将→上六论功行赏）；③卦与卦之间的对立转化（乾坤、泰否、损益）；上爻多主"物极必反"；④涉及政治（同人、革）、伦理（家人、归妹）、经济（节、贲）、法制（讼、夬）思想。
- 核心：**阴阳变化的规律**。程颐："散之在理则有万殊，统之在道则无二致。"
- 《易传》：解经的哲学著作，与经不可割裂。"以经解画，以传解经；合则是，而离则非。"

## 四、易学的流派

- **象数派**：用卦象、数解易，汉儒为主（孟喜、京房、郑玄、荀爽、虞翻）；流弊是执泥卦象、掺杂术数。
- **义理派**：阐明哲学大义，王弼开风气（兼用老庄），胡瑗、程颐发展为儒理，李光、杨万里以史证易。
- 清四库馆臣的"两派六宗"：左传占筮 → 汉儒象数 → 京焦（入祥）→ 陈邵（穷造化）→ 王弼（尽黜象数）→ 胡程（儒理）→ 李杨（史事）。
- 宋代陈抟、刘牧、邵雍出"先天图""河图洛书"，朱熹采入《周易本义》，与汉易对峙，称"宋易"。清代惠栋等攻宋学，复汉易。
- 吴承仕："名物为象数所依，象数为义理而设"：两派应当互用。
- 近代有影响者：杭辛斋（贯通新旧）、尚秉和（专研象数，解决大量易象问题）。《帛书周易》（马王堆）卦序、文字与通行本不同，卦序以上卦为纲分八组，似是实用改编。

## 五、研读《周易》的八项方法（译注者的主张）

1. 从源溯流：先熟读经传，读《左传》《国语》古筮例，再读汉魏古注（《周易集解》），再读六朝隋唐义疏（《正义》），最后看宋元以后。
2. 强干弱枝：以象数、义理为主干，天文地理乐律兵法等是枝附。
3. 以传解经：《易传》是解经首要依据。
4. 掌握"象征"：易说一个物不是真的物（朱熹："说龙非真龙"）。
5. 掌握易例：爻位、承乘比应、卦时、卦主、中正。
6. 结合考古发现（帛书周易、数字卦）。
7. 多学科比较（文学、史学、美学、音韵、科技史）。
8. 参考国外研究。

## 六、大衍筮法（《筮仪》，十八变成一卦）

> 朱熹《周易本义》卷首的《筮仪》，译注者节录。本技能的 `scripts/cast.py` 用的是**三枚铜钱**起卦，是它的简化；下面是原始蓍草法，留作参考。

1. 取蓍草50根，取出1根不用，余49根随意分成左右两堆（**分二**，象两仪）。
2. 从右堆取1根挂在左手小指间（**挂一**，象三才）。
3. 左堆四根一数（**揲四**，象四时），把余数（1到4）夹在无名指间（**归奇**，象闰）。
4. 右堆同样四根一数，余数夹在中指间（**再扐**，象再闰）。
5. 把挂的1根和两个余数合起来放一旁。第一变后，挂扐之数不是5就是9（5为奇，9为偶）。
6. 剩下的蓍草合并再来一遍，第二变挂扐之数不是4就是8；第三变同第二变。
7. 三变为一爻：把三变的挂扐之数相加，判定：
   - 三个都是奇（5、4、4共13）→ 过揲36策 → **老阳（九）**，画成"□"（重）；
   - 两奇一偶（17）→ 过揲32 → **少阴（八）**，画"--"；
   - 两偶一奇（21）→ 过揲28 → **少阳（七）**，画"一"；
   - 三个都是偶（25）→ 过揲24 → **老阴（六）**，画"×"（交）。
   把过揲之数除以4得到9、8、7、6。
8. 十八变（6爻×3变）成一卦。

## 七、易图述略

宋以前没有易图；周敦颐传陈抟"太极图"之后图说才兴盛。朱熹把邵雍的几张图放在《周易本义》卷首（王懋竑考证这九图是后人依《易学启蒙》补入）。杭辛斋："先辨图书，识其阴阳生化之原、奇偶交变之义，而后观象玩辞，有所准的。"

- **太极图**：最流行的"先天太极图"，黑白回互表示阴阳二气运行；严格说应叫"两仪生四象、四象生八卦之图"。
- **河图**：一六居下，二七居上，三八居左，四九居右，五十居中（五行生成数）。**洛书**：戴九履一，左三右七，二四为肩，六八为足，五居中（九宫数；纵横斜相加均15）。
  ```
  四 九 二
  三 五 七
  八 一 六
  ```
  朱熹《易学启蒙》：河图是"数之体"（全），洛书是"数之用"（变）；天数五（一三五七九）、地数五（二四六八十），合为55；河图象太极、两仪、四象、八卦；洛书则对应《洪范》九畴。传说伏羲得河图画卦、夏禹得洛书演洪范。
- **先天八卦方位**（邵雍传，又称伏羲八卦）：乾南坤北、离东坎西、震东北、兑东南、巽西南、艮西北。解《说卦》"天地定位，山泽通气，雷风相薄，水火不相射"。尚秉和认为汉代已有，焦延寿《易林》都用。
- **后天八卦方位**（又称文王八卦、帝出乎震图）：震东、兑西、离南、坎北为四正卦；乾西北、坤西南、艮东北、巽东南为四隅卦。解《说卦》"帝出乎震"一节。尚秉和：后天由先天变来——先天乾南坤北、离东坎西，阴阳相交（坤南交乾则南方成离；乾北交坤则北方成坎），由静而动。经文里坤卦、蹇卦用后天方位（西南），既济九五用先天位（离东坎西）。
- **十二辟卦（消息卦）**：配十二月，指示阴阳消长。复（子/十一月，一阳）→临（丑）→泰（寅）→大壮（卯）→夬（辰）→乾（巳，六阳）为息卦；姤（午，一阴）→遯（未）→否（申）→观（酉）→剥（戌）→坤（亥，六阴）为消卦。尚秉和称为"全《易》之本根"。"辟"是君、主的意思。这和《复》卦"七日来复"的解释相关。
- **二十四方位图**：以八卦配干支，即二十四山（指南针方位）。四正卦所在的地支（子午卯酉）直接用支；四隅卦（乾艮巽坤）配夹它的两个地支（戌亥夹乾，丑寅夹艮，辰巳夹巽，未申夹坤）；八干（甲乙夹震，丙丁夹离，庚辛夹兑，壬癸夹坎）辅四正；不用戊己（中央土无定位）。共24。
- **卦气图**（孟喜）：坎离震兑为四正卦主四时，每爻主一个节气（24气）；其余六十卦每卦主六日七分（合周天365又1/4日）；辟卦十二主十二月（爻主72候）；辟卦为君、杂卦为臣、四正为方伯。用于历法与占验，也被用来解释复卦"七日来复"。
- **六十四卦方位图（伏羲六十四卦方圆图）**：外圆内方，邵雍的"先天之学"。阳卦始于复、极于乾；阴卦始于姤、极于坤。复至乾共112阳、80阴；姤至坤共112阴、80阳。莱布尼茨曾认为这图的排列与二进制相合。邵雍："先天学，心法也。"

## 九、译注体例（《译注简说》，了解数据来源用）

- 底本：阮刻《十三经注疏》本《周易正义》；象数义理两派择善而从；
- 每卦有原文、译文、注释、说明（对该爻/节的补充）、总论（全卦大义，64篇；另有五篇分论系辞上下、说卦、序卦、杂卦）；
- 引旧注一般只取一说；个别重要处两三说并存；
- 《周易折中》《重定费氏学》《周易学说》所引前人易说常是节引，反映引用者自己的见解；
- 译注者强调：《周易》是以筮书面目出现的古代哲学著作，含辩证法思想，但也杂糅占筮色彩，要批判地读。
