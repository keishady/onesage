# 周易64卦索引

使用方法：先在「情境速查」里按用户的局面找候选卦 → 打开对应卦文件，用「判断要点」核对 → 定爻 → 给对策。
卦名链接指向 `hexagrams/` 下的文件。

## 一、情境速查（按局面找卦）

**1. 该主动出击、势头在我**：乾（全面主导）、大壮（强但要克制）、夬（最后一击清除小人）、临（上升期亲自下沉）、晋（被赏识晋升）、升（循序往上爬）、大有（资源丰盛）、履（在强者旁谨慎前行）
**2. 该等待、积累、蓄力**：需（等外部条件）、小畜（小有积累被牵制）、大畜（长期蓄力待发）、屯（草创艰难）、蒙（认知不足需学习）、观（先观察看清）
**3. 该退、止、守**：遯（体面撤退）、艮（适可而止）、剥（趋势下滑止损）、明夷（被压制要韬光养晦）、谦（放低姿态）、坤（做配合与承载）、节（设边界与克制）、小过（只做小事别冒进）
**4. 冲突、对立、分歧**：讼（争执纠纷）、睽（意见背离）、师（组织对抗）、噬嗑（清除障碍/处理违规）、姤（防不期而遇的苗头）、否（上下不通）
**5. 困境、险境**：坎（重重险陷）、蹇（前有险后有阻）、困（穷困被孤立）、大过（负荷超载）、震（突发冲击）、涣（涣散离散）
**6. 转机、解脱、重启**：复（低谷后回春）、解（危难解除）、泰（上下通畅）、未济（未完成，开启新循环）、革（旧法已穷该变）、鼎（立新秩序）
**7. 合作、关系、人际**：比（择人结盟）、同人（志同道合）、萃（聚人）、咸（互相感应）、随（跟随时势）、中孚（以诚信相通）、家人（内部治理）、归妹（名分未正的关系）、渐（循序推进）、兑（沟通喜悦）
**8. 整顿、更新、增减**：蛊（清理积弊）、井（长期供给与维护）、益（得到助益、趁势做大）、损（主动减损让利）、革（变革）
**9. 盛、成、满**：大有（丰盛）、丰（盛极）、既济（完成后防松懈）、豫（顺势喜悦）、泰（通畅）
**10. 姿态与方法**：巽（柔性渗透）、恒（长期坚持）、离（依附光明）、无妄（守真不投机）、贲（包装修饰）、颐（养与言食）、旅（在外寄身）

## 五、爻位通则（拿不准具体爻辞时用）

- 初：发端、潜伏、势微 → 观察、准备，不宜大动
- 二：居下卦之中，可试、可见 → 站稳、试探、找贵人
- 三：下卦之终，多危 → 压力峰值，克制、复盘
- 四：入上卦之初，多惧 → 进入新环境，审时度势，可进可退
- 五：居上卦之中，当位 → 成熟得势，最宜作为
- 上：过位、穷极 → 见好就收、防反转
- 阳爻当位在初、三、五，阴爻当位在二、四、上；当位者稳，失位者多需调整。
