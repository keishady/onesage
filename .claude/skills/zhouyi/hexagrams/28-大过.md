# 第28卦 大过（兑上巽下）· 栋梁弯曲，非常时期需非常之举

**卦辞**：栋桡，利有攸往，亨。
**态势**：中间太重、两头太弱，负荷超出承受，必须非常规手段；既要谨慎又要有担当。
**像这样的事**：重大危机、压力过载、超出能力范围的任务、关键时刻要做特殊决定、需要大胆承担责任。
**判断要点**：① 负荷过大，常规办法不行；② 基础（头尾）薄弱；③ 不处理会塌，处理则需要胆识。
**对策**
- 宜：果敢担当、分散压力、先加固根基、寻找能撑住的人、行动要稳。
- 忌：硬扛到崩、孤注一掷、拖着不改、过度保守。

**六爻**
- 初六 藉用白茅，无咎：用白茅垫底。→ 以极致的谨慎对待起步，无咎。
- 九二 枯杨生稊，老夫得其女妻，无不利：枯树发芽。→ 在旧体系中引入新活力，有利。
- 九三 栋桡，凶：栋梁弯折。→ 过分刚强、不听建议，必垮；立刻减负。
- 九四 栋隆，吉；有它吝：栋梁隆起。→ 能撑住大局则吉，但有外援可能带来牵扯。
- 九五 枯杨生华，老妇得其士夫，无咎无誉：开花但无果。→ 表面复苏、实质不足，不宜张扬。
- 上六 过涉灭顶，凶，无咎：涉水过深淹顶。→ 冒险过度必有损失，但出于担当则可谅。

**走向**：担当得宜转坎（险后可渡）；一直硬撑则转困。
