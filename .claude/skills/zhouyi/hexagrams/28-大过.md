# 第28卦 大过（兑上巽下）· 栋梁弯曲，非常时期需非常之举

**卦辞**：栋桡，利有攸往，亨。
**彖传**：大过，大者过也；栋桡，本末弱也。刚过而中，巽而说行，利有攸往，乃亨。大过之时大矣哉！
**大象**：泽灭木，大过；君子以独立不惧，遯世无闷。
**态势**：中间太重、两头太弱，负荷超出承受，必须非常规手段；既要谨慎又要有担当。
**像这样的事**：重大危机、压力过载、超出能力范围的任务、关键时刻要做特殊决定、需要大胆承担责任。
**判断要点**：① 负荷过大，常规办法不行；② 基础（头尾）薄弱；③ 不处理会塌，处理则需要胆识。
**对策**
- 宜：果敢担当、分散压力、先加固根基、寻找能撑住的人、行动要稳。
- 忌：硬扛到崩、孤注一掷、拖着不改、过度保守。

**卦理**（据《周易译注》总论提炼）
- 《大过》是大为过甚：阳刚过盛、阴柔极弱，如栋梁曲折下挠（本末弱）。卦辞“栋桡，利有攸往，亨”：此时亟待非常之举（大过人）来拯治。
- 救弊之道是刚柔互济：上下两阴须取刚济柔，中间四阳须取柔济刚。初、二相比善调（初无咎、二无不利）；五、上相比但阴阳悬殊太甚，竭力仍难完满（五无咎无誉，上凶无咎）；三、四两阳离阴最远，须自损阳刚、静居顺调：三违逆致凶，四遵循获吉。根本原则：刚柔相济、力求平衡。“非同寻常”之象：枯杨生稊/生华，老夫得女妻、老妇得士夫。
- 上六过涉灭顶有杀身成仁之旨；大象“独立不惧，遁世无闷”：危而不持、颠而不扶，则将焉用彼相。
**二体**：下巽上兑；**互卦**：乾（二三四为下互，三四五为上互）

**六爻**
- 初六 藉用白茅，无咎：用白茅垫底。→ 以极致的谨慎对待起步，无咎。
  - 小象：藉用白茅，柔在下也。
  - 爻位：初阴、不当位、与四爻有应、承阳（托着上面的阳爻）
  - 爻理：“藉用白茅，无咎”：以柔弱处极下，敬慎承阳；白茅虽薄用可重，慎之至也。
- 九二 枯杨生稊，老夫得其女妻，无不利：枯树发芽。→ 刚强过盛之时，以柔济刚：放软姿态、引入新活力，有利。
  - 小象：老夫女妻，过以相与也。
  - 爻位：二阳、不当位、居中、与五爻无应（同性相敌）
  - 爻理：“枯杨生稊，老夫得其女妻，无不利”：阳居阴位再济以初之阴柔；大过之阳皆以居阴为吉，不以得位为美（刚已过正可济以柔）。
- 九三 栋桡，凶：栋梁弯折。→ 过分刚强、不听建议，必垮；立刻减负。
  - 小象：栋桡之凶，不可以有辅也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“栋桡，凶”：他卦三应上本佳，大过之时刚可损不可益；不可以有辅。
- 九四 栋隆，吉；有它吝：栋梁隆起。→ 能撑住大局则吉，关键是自损过刚、不去与下面柔弱的牵扯；另寻外援反而添麻烦。
  - 小象：栋隆之吉，不桡乎下也。
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“栋隆，吉；有它吝”：三四都不宜应爻：三以刚亢应上则更亢，四以刚柔调济之质若应初则趋下过柔，栋隆复挠；自损阳刚、不与初应即吉。
- 九五 枯杨生华，老妇得其士夫，无咎无誉：开花但无果。→ 表面复苏、实质不足，不宜张扬。
  - 小象：枯杨生华，何可久也？老妇士夫，亦可丑也
  - 爻位：五阳、当位、居中、与二爻无应（同性相敌）
  - 爻理：“枯杨生华，老妇得其士夫，无咎无誉”：以极刚济极柔，竭尽最后努力但大势所然，非人力所能改，不可久。
- 上六 过涉灭顶，凶，无咎：涉水过深淹顶。→ 冒险过度必有损失，但出于担当则可谅。
  - 小象：过涉之凶，不可咎也。
  - 爻位：上阴、当位、与三爻有应、乘刚（压在阳爻上）
  - 爻理：“过涉灭顶，凶，无咎”：栋梁末端不胜重负；救不得时毅然自损保全主体，大屋赖以不陷；时无可为甘罹其凶，所以无咎。

**走向**：担当得宜转坎（险后可渡）；一直硬撑则转困。
