# 第53卦 渐（巽上艮下）· 循序渐进，稳步成事

**卦辞**：女归吉，利贞。
**彖传**：渐之进也，女归吉也。进得位，往有功也；进以正，可以正邦也。其位，刚得中也；止而巽，动不穷也。
**大象**：山上有木，渐；君子以居贤德善俗。
**态势**：急不得，一步步按次序走才能成；像鸿雁飞过一站又一站，每一站都稳。
**像这样的事**：婚姻/感情推进、职业晋升的阶梯、慢热的业务、长期学习、渐进式改革。
**判断要点**：① 成事需要时间与阶段；② 提前跳步会出问题；③ 当前阶段要做好才能上下一阶段。
**对策**
- 宜：分阶段、守次序、保持耐心、不躁进、坚持正道。
- 忌：急于求成、越级、因慢而焦虑、半途改道。

**六爻**
- 初六 鸿渐于干，小子厉，有言，无咎：鸿雁刚到水边。→ 起步有小议论，别在意，稳稳地走。
  - 小象：小子之厉，义无咎也。
- 六二 鸿渐于磐，饮食衎衎，吉：到了磐石。→ 找到安稳点，享受阶段性成果，吉。
  - 小象：饮食衍衍，不素饱也。
- 九三 鸿渐于陆，夫征不复，妇孕不育，凶，利御寇：到了高陆。→ 冒进脱离群体，凶；要防守，别妄进。
  - 小象：夫征不复，离群丑也；妇孕不育，失其道也；利用御寇，顺相保也。
- 六四 鸿渐于木，或得其桷，无咎：停在树上。→ 找到合适的枝落脚，灵活应变，无咎。
  - 小象：或得其桷，顺以巽也
- 九五 鸿渐于陵，妇三岁不孕，终莫之胜，吉：到了山陵。→ 虽然阻力时间长，终将成功，吉。
  - 小象：终莫之胜吉，得所愿也。
- 上九 鸿渐于陆，其羽可用为仪，吉：飞到高空。→ 成事后成为他人的榜样，吉。
  - 小象：其羽可用为仪吉，不可乱也。

**走向**：渐成则转归妹/既济；躁进则转蹇。
