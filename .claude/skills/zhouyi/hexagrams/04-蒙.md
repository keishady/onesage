# 第4卦 蒙（艮上坎下）· 蒙昧未明，需要启蒙与学习

**卦辞**：亨。匪我求童蒙，童蒙求我。初筮告，再三渎，渎则不告。利贞。
**彖传**：蒙，山下有险，险而止，蒙。蒙亨，以亨行时中也。匪我求童蒙，童蒙求我，志应也。初筮告，以刚中也；再三渎，渎则不告，渎蒙也。蒙以养正，圣功也。
**大象**：山下出泉，蒙；君子以果行育德。
**态势**：你（或对方）对情况认识不清，处于"不知道自己不知道"的阶段；关键在求教、学习、纠偏，而不是急着行动。
**像这样的事**：新手入门、对行业/规则不熟、被信息迷惑、教育孩子/带新人、需要拜师。
**判断要点**：① 决策依据不足；② 有人能指点但你没去问，或你在指导对方；③ 犹豫来自"看不清"。
**对策**
- 宜：诚心求教、一次问清关键问题、给明确规则、小步试错、立规矩。
- 忌：不懂装懂、反复纠缠同一问题不行动、教导时一味溺爱或一味打压。

**卦理**（据《周易译注》总论提炼）
- 讲怎样启蒙。卦辞“匪我求童蒙，童蒙求我”：求学者主动，施教者不上门强教；“初筮告，再三渎则不告”：启发式教学，反复滥问就不再告诉。
- 六爻：两个阳爻是师（九二刚而得中，宽以包容；上九刚极不中，严以击之），四个阴爻是蒙者；六五居尊谦下好学，初六潜心发蒙，三、四或不循学径、或远离师长而困。
- 一句话：在蒙者要去求明，在明者要去发蒙，各有各的道。
**二体**：下坎上艮；**互卦**：复（二三四为下互，三四五为上互）

**六爻**
- 初六 发蒙，利用刑人，用说桎梏，以往吝：启蒙之初要立规矩。→ 先定规则与边界，但不可长期严苛。
  - 小象：利用刑人，以正法也。
  - 爻位：初阴、不当位、与四爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：阴爻在最下，蒙稚最深，最需要启发。
- 九二 包蒙，吉；纳妇吉，子克家：包容愚昧者，能担责。→ 当包容的带教者/负责人，宽容中带担当。
  - 小象：子克家，刚柔接也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：包蒙、纳妇、子克家，都归结到阳刚居中、启迪蒙稚。“子克家”如臣事君：责难纳诲、陈善闭邪是分内事。师道不论年长年幼，道之所在即师之所在。
- 六三 勿用取女，见金夫，不有躬，无攸利：见利忘本。→ 别被表面好处诱惑，守住自己的原则与判断。
  - 小象：勿用取女，行不顺也。
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）
  - 爻理：比喻在蒙稚之时，不可把启蒙教育放一边而盲目躁进；立身先要有廉耻。
- 六四 困蒙，吝：困在无知里无人指点。→ 主动找老师/资料，别闭门造车。
  - 小象：困蒙之吝，独远实也。
  - 爻位：四阴、当位、与初爻无应（同性相敌）
  - 爻理：不亲近老师（“学莫便乎近其人”），所以困于蒙而有吝。
- 六五 童蒙，吉：虚心如童，得吉。→ 保持空杯，信任可靠的指导。
  - 小象：童蒙之吉，顺以巽也。
  - 爻位：五阴、不当位、居中、与二爻有应、承阳（托着上面的阳爻）
  - 爻理：“蒙以养正”：六五自己不正，要去应九二，靠它培养自己的正（一说）。
- 上九 击蒙，不利为寇，利御寇：对顽固者要强力纠正，但不过度。→ 只防止错误，不以暴制暴。
  - 小象：利用御寇，上下顺也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：蒙师气质不同、蒙者程度不一，治蒙的方式也不同：九二用宽，上九用猛。

**走向**：蒙而得启则转需（有了认知，等待时机）；一直蒙昧则困于讼/险。
