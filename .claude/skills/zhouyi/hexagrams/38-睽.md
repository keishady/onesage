# 第38卦 睽（离上兑下）· 乖离背向，求同存异，小事可成

**卦辞**：小事吉。
**彖传**：睽，火动而上，泽动而下；二女同居，其志不同行。说而丽乎明，柔进而上行，得中而应乎刚，是以小事吉。天地睽而其事同也，男女睽而其志通也，万物睽而其事类也：睽之时用大矣哉！
**大象**：上火下泽，睽；君子以同而异。
**态势**：人心、方向、观点背道而驰，大事难合；但小事可成，要学会在分歧中找最小共识。
**像这样的事**：团队意见严重分歧、夫妻/合伙人观点相左、各部门不配合、对方误会你。
**判断要点**：① 目标不一致或理解错位；② 沟通频繁出现误解；③ 强求统一会激化。
**对策**
- 宜：求同存异、先做小事建立信任、少争论多行动、通过第三方沟通、耐心等待对方转变。
- 忌：强行统一、拿大事考验分歧、冷战、恶意揣测。

**卦理**（据《周易译注》总论提炼）
- 《睽》是乖背睽违，但卦旨在于如何化睽为合：卦辞“小事吉”：用柔和细致方法顺势利导，乖背可消。没有一爻久睽不合：初“丧马勿逐”到四“遇元夫”，初四合；二“遇主于巷”到五“往何咎”，二五合；三“舆曳牛掣”到上“遇雨”，三上合。委曲巽入则易通。
- 天地睽而其事同、男女睽而其志通、万物睽而其事类：对立统一；大象“同而异”：求大同存小异。
**二体**：下兑上离；**互卦**：既济（二三四为下互，三四五为上互）

**六爻**
- 初九 悔亡，丧马勿逐，自复；见恶人，无咎：失去也别追。→ 分歧初起，不标新立异、不追逐，静以待之，自然会回；与"坏人"打交道也不必避嫌。
  - 小象：见恶人，以辟咎也
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“悔亡，丧马勿逐，自复；见恶人，无咎”：和光同尘、不标显自异；静以俟之，逊以接之，泊然若不见其睽，睽乃可合。
- 九二 遇主于巷，无咎：在巷子里偶遇主人。→ 不拘形式地私下沟通，不失体面，解决问题。
  - 小象：遇主于巷，未失道也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“遇主于巷，无咎”：刚而能柔，行不失中；不强求合，睽自合。
- 六三 见舆曳，其牛掣，其人天且劓，无初有终：处处受阻。→ 先被刁难，但坚持下去，终有好结果。
  - 小象：见舆曳，位不当也；无初有终，遇刚也。
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“见舆曳，其牛掣，其人天且劓，无初有终”：“天”字三说：刻额之刑；“而”（髡鬓）之误；“兀”之误（断足）。三种都是受刑受辱；无初有终，遇刚也。
- 九四 睽孤，遇元夫，交孚，厉无咎：孤立中遇到志同者。→ 在孤立时遇到可信的人，以诚相交，化险为夷。
  - 小象：交孚无咎，志行也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“睽孤，遇元夫，交孚，厉无咎”：初与四都禀谦和之德，交相孚信，以求同存异之念济睽。
- 六五 悔亡，厥宗噬肤，往何咎：宗亲能亲近。→ 当有人愿意靠近时，放下顾虑，往前走，无咎。
  - 小象：厥宗噬肤，往有庆也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“悔亡，厥宗噬肤，往何咎”：九二相应，更在二小心寻求平易和顺之道；往必有庆。
- 上九 睽孤，见豕负涂，载鬼一车，先张之弧，后说之弧：疑心生暗鬼。→ 极度猜疑会幻觉，要放下弓箭，疑解则合，真相是友非敌。
  - 小象：遇雨之吉，群疑亡也
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“睽孤，见豕负涂，载鬼一车，先张之弧，后说之弧，匪寇婚媾，往遇雨则吉”：睽违猜疑生幻象（豕负涂、鬼载一车）；睽极群疑纷生，心平气和加强了解、以柔道疏通，则消疑合睽；遇雨则吉。

**走向**：疑解则转蹇/解；睽极则转蹇（险阻）。
