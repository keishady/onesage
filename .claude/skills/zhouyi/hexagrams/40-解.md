# 第40卦 解（震上坎下）· 危难解除，宜速回正轨、不留后患

**卦辞**：利西南，无所往，其来复吉；有攸往，夙吉。
**彖传**：解，险以动，动而免乎险，解。解利西南，往得众也；其来复吉，乃得中也；有攸往，夙吉，往有功也。天地解而雷雨作，雷雨作而百果草木皆甲坼：解之时大矣哉！
**大象**：雷雨作，解；君子以赦过宥罪。
**态势**：困境开始松动，压力释放，是处理遗留问题、恢复秩序的窗口；该速决的速决，该休养的休养。
**像这样的事**：官司和解、困境缓解、债务重组、冲突解开、病情好转、危机后的善后。
**判断要点**：① 最紧的时候已过；② 还有遗留的小问题；③ 要不要继续行动有明确选择。
**对策**
- 宜：没有事就回复常态；有事则尽快处理，别拖；宽恕、轻罚、止损、保留教训。
- 忌：放松警惕又陷旧坑、揪着过去不放、只庆祝不善后。

**卦理**（据《周易译注》总论提炼）
- 《解》是舒解险难：卦辞“利西南，无所往，其来复吉；有攸往，夙吉”：无难就回到安居处为吉；有难就早去速解，不要久缠扰。目的是追求安宁平和的环境。
- 六爻侧重“去小人、排内患”：全卦之难集于六三（阴居内卦坎险之上，以阴居阳位的小人窃位）；诸爻皆欲去之：二获狐（获三）、四解拇（解三）、五有孚退三、上射隼（射三）；初六才柔位卑，只在解时无咎。矛盾在“内”在“隐”。
**二体**：下坎上震；**互卦**：既济（二三四为下互，三四五为上互）

**六爻**
- 初六 无咎：刚解脱，自然无咎。→ 稳住节奏，别多事。
  - 小象：刚柔之际，义无咎也。
  - 爻位：初阴、不当位、与四爻有应、承阳（托着上面的阳爻）
  - 爻理：“无咎”：只二字，象在爻中；与《恒》九二悔亡、《大壮》九二贞吉同，简而不言。
- 九二 田获三狐，得黄矢，贞吉：打到三只狐。→ 清除内部的奸诈小人（三狐），以中正之道办，吉。
  - 小象：九二贞吉，得中道也
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“田获三狐，得黄矢，贞吉”：阳居阴位似失正，但刚直处中，有黄矢之美，能排除隐患；得中道。
- 六三 负且乘，致寇至，贞吝：背着东西又坐车。→ 位不配德招人觊觎，别炫耀，别占不该占的位。
  - 小象：负且乘，亦可丑也；自我致戎，又谁咎也？
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“负且乘，致寇至，贞吝”：负是小人之事，乘是君子之器，小人乘君子之器，盗思夺之；上慢下暴，盗思伐之；慢藏诲盗，治容诲淫；窃据高位的根源在上者任人轻忽；自我致戎。
- 九四 解而拇，朋至斯孚：解开脚趾上的牵绊。→ 切断不良牵连，真正的朋友才会来。
  - 小象：解而拇，未当位也。
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“解而拇，朋至斯孚”：二、四皆有王臣象而居位未正：九二赖中德获三狐，九四被小人纠附，一因居位未当、一因不中。
- 六五 君子维有解，吉，有孚于小人：君子能自解。→ 以诚信瓦解对手，让小人也折服，吉。
  - 小象：君子有解，小人退也
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）
  - 爻理：“君子维有解，吉，有孚于小人”：柔中之德舒难，以诚信感化小人，转邪为善，也排除隐患。
- 上六 公用射隼于高墉之上，获之，无不利：射中高墙上的隼。→ 对最后的顽固威胁，择时出手，一击中的；平时要藏器于身、待时而动，别因一时解脱忘了新患。
  - 小象：公用射隼，以解悖也
  - 爻位：上阴、当位、与三爻无应（同性相敌）
  - 爻理：“公用射隼于高墉之上，获之，无不利”：隼者禽也，弓矢者器也，射之者人也；君子藏器于身，待时而动，何不利之有；解极新患或萌，应预藏成器随时警惕，不可忘他日之蹇。

**走向**：善后得宜转需/既济；放松则回蹇/坎。
