# 第40卦 解（震上坎下）· 危难解除，宜速回正轨、不留后患

**卦辞**：利西南，无所往，其来复吉；有攸往，夙吉。
**态势**：困境开始松动，压力释放，是处理遗留问题、恢复秩序的窗口；该速决的速决，该休养的休养。
**像这样的事**：官司和解、困境缓解、债务重组、冲突解开、病情好转、危机后的善后。
**判断要点**：① 最紧的时候已过；② 还有遗留的小问题；③ 要不要继续行动有明确选择。
**对策**
- 宜：没有事就回复常态；有事则尽快处理，别拖；宽恕、轻罚、止损、保留教训。
- 忌：放松警惕又陷旧坑、揪着过去不放、只庆祝不善后。

**六爻**
- 初六 无咎：刚解脱，自然无咎。→ 稳住节奏，别多事。
- 九二 田获三狐，得黄矢，贞吉：打到三只狐。→ 清除内部的奸诈小人（三狐），以中正之道办，吉。
- 六三 负且乘，致寇至，贞吝：背着东西又坐车。→ 位不配德招人觊觎，别炫耀，别占不该占的位。
- 九四 解而拇，朋至斯孚：解开脚趾上的牵绊。→ 切断不良牵连，真正的朋友才会来。
- 六五 君子维有解，吉，有孚于小人：君子能自解。→ 以诚信瓦解对手，让小人也折服，吉。
- 上六 公用射隼于高墉之上，获之，无不利：射中高墙上的隼。→ 对最后的顽固威胁，择时出手，一击中的；平时要藏器于身、待时而动，别因一时解脱忘了新患。

**走向**：善后得宜转需/既济；放松则回蹇/坎。
