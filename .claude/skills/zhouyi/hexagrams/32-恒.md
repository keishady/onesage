# 第32卦 恒（震上巽下）· 持之以恒，恒而能变

**卦辞**：亨，无咎，利贞，利有攸往。
**彖传**：恒，久也。刚上而柔下，雷风相与，巽而动，刚柔皆应，恒。恒亨，无咎利贞，久于其道也。天地之道，恒久而不已也；利有攸往，终则有始也。日月得天而能久照，四时变化而能久成，圣人久于其道而天下化成：观其所恒，而天地万物之情可见矣！
**大象**：雷风，恒；君子以立不易方。
**态势**：事情要靠长期坚持才能成，但"恒"不是僵化，而是在变化中守住不变的核心。
**像这样的事**：长期主义的事业、婚姻与长期关系、习惯养成、坚持一项技能、持续经营。
**判断要点**：① 成果需要时间；② 你面临"该不该坚持"的抉择；③ 要分清是原则性的恒还是形式的僵化。
**对策**
- 宜：坚守核心、小步长期、遇变则调整手段不改方向、做长期复盘。
- 忌：三天打鱼、过度死板、见异思迁、忘记初衷、只坚持形式不看效果。

**卦理**（据《周易译注》总论提炼）
- 《恒》是恒久，教人持之以恒。卦辞“亨，无咎，利贞，利有攸往”：恒道可行。但六爻无一爻全吉：恒之道岂易言哉；路遥知马力，日久识人心。
- 初六急于深求恒（浚恒贞凶）；九二失位却能守中消悔；九三守德不恒或承之羞；九四久居非位，田无禽；六五恒守柔德妇人吉夫子凶；上六振恒（躁动不能守恒）凶。无论占语如何，要旨都是勉人守正处恒；人贵有恒（荀子：锲而不舍金石可镂）。
**二体**：下巽上震；**互卦**：夬（二三四为下互，三四五为上互）

**六爻**
- 初六 浚恒，贞凶，无攸利：一开始就要求太深。→ 开局不要求过深过快，循序渐进。
  - 小象：浚恒之凶，始求深也。
  - 爻位：初阴、不当位、与四爻有应、承阳（托着上面的阳爻）
  - 爻理：“浚恒，贞凶，无攸利”：在初就求恒的深远之效，欲速不达：为学之始欲至周孔，为治之始欲化尧舜；恒要积日累久。
- 九二 悔亡：悔恨消去。→ 把握适中，恰到好处，守中。
  - 小象：九二悔亡，能久中也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“悔亡”：不当位但能恒久守中；可久之道无它，中而已，过犹不及皆非可久。
- 九三 不恒其德，或承之羞，贞吝：德行不稳。→ 缺乏定力会招羞辱，要稳。
  - 小象：不恒其德，无所容也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“不恒其德，或承之羞，贞吝”：守德不恒者，孔子鄙夷“人而无恒，不可以作巫医”，“不占而已矣”。
- 九四 田无禽：打猎无获。→ 方向或位置不对，再坚持也无用，要换位置。
  - 小象：久非其位，安得禽也？
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“田无禽”：不当位又失中，劳而无获；失方向的恒只滋乱：久于仁义之政才能化民正君。
- 六五 恒其德，贞，妇人吉，夫子凶：守恒顺从。→ 对守成事务适合坚持，对需要变革者需灵活。
  - 小象：妇人贞吉，从一而终也；夫子制义，从妇凶也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）
  - 爻理：“恒其德，贞，妇人吉，夫子凶”：恒守柔顺，以顺为正对妇人是吉，对丈夫是凶（带有古代妇从夫礼教的时代色彩）。
- 上六 振恒，凶：一味躁动。→ 在最高位还不停变动，不吉，应该静守。
  - 小象：振恒在上，大无功也。
  - 爻位：上阴、当位、与三爻有应
  - 爻理：“振恒，凶”：初在下求恒过深，上居终不能守恒，两者相反而都违恒道；立大功必悠久胶固，振动躁扰、暂作易辍，安能成功。

**走向**：恒而能变转大壮/益；若僵化则转遯。
