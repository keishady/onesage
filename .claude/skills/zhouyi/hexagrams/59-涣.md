# 第59卦 涣（巽上坎下）· 涣散离散，以诚聚心，化解隔阂

**卦辞**：亨，王假有庙，利涉大川，利贞。
**彖传**：涣亨，刚来而不穷，柔得位乎外而上同。王假有庙，王乃在中也。利涉大川，乘木有功也。
**大象**：风行水上，涣；先王以享于帝立庙。
**态势**：人心、团队、资源正在散开、隔阂出现；要用共同的信念与目标重新凝聚，也可以借"散"来化解僵局。
**像这样的事**：团队涣散、关系疏远、僵局需要打破、观念松动、组织调整、化解积怨。
**判断要点**：① 力量分散；② 阻隔在心理而非实际；③ 需要新的向心点。
**对策**
- 宜：重塑共同目标、仪式感、公开透明、拆除壁垒、主动化解对立、先内后外。
- 忌：任由涣散、强压团结、只靠制度没有感情、把散当终点。

**卦理**（据《周易译注》总论提炼）
- 《涣》是涣散：并非散乱，而是“散”与“聚”互相依存：卦辞“亨，王假有庙，利涉大川，利贞”：君王祭庙聚合神灵之佑，涉大河聚合人心济难；形虽散而神能聚必致亨通。涣者其形迹，不涣者其精神；风行水上自然成文，形散神聚。
- 六爻虽在涣散之时，阴阳相比相应已流露聚的气象：初六用拯马壮吉（救之尚早，可不至涣）；九二涣奔其机悔亡（固本，凭依安居）；六三涣其躬无悔；六四涣其群元吉（散小群聚大群，涣小人之私群成天下之公道）；九五涣汗其大号，涣王居无咎（散居积聚民心）；上九涣其血去逖出无咎（散极见聚）。涣其所当涣，则不当涣者聚矣。
**二体**：下坎上巽；**互卦**：颐（二三四为下互，三四五为上互）

**六爻**
- 初六 用拯马壮，吉：用强壮的马救援。→ 趁涣散刚起，迅速用有力的措施补救，吉。
  - 小象：初六之吉，顺也。
  - 爻位：初阴、不当位、与四爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“用拯马壮，吉”：处坎险之下，涣散初始及早拯之；五爻皆言涣，初独不言，救之尚早。
- 九二 涣奔其机，悔亡：奔向依靠的几案。→ 在涣散中靠回稳固的根据，后悔消失。
  - 小象：涣奔其机，得愿也。
  - 爻位：二阳、不当位、居中、与五爻无应（同性相敌）
  - 爻理：“涣奔其机，悔亡”：阳刚居中，得阴阳相合之愿，固其根本而聚时之所散；机：几案，有所凭依而安居，然后动而不穷。
- 六三 涣其躬，无悔：放下自我。→ 放下私我、小我，投入大目标，无悔。
  - 小象：涣其躬，志在外也。
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）
  - 爻理：“涣其躬，无悔”：散其自身（舍己）附从尊者；当散则散，当聚则聚。
- 六四 涣其群，元吉；涣有丘，匪夷所思：解散小团体。→ 打破派系、聚成更大的共同体，大吉。
  - 小象：涣其群元吉，光大也。
  - 爻位：四阴、当位、与初爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“涣其群，元吉。涣有丘，匪夷所思”：群是圣人欲涣以混一天下者；人心涣散各相朋党，唯六四能涣小人之私群成天下之公道；涣有丘：散中聚成大丘。
- 九五 涣汗其大号，涣王居，无咎：像汗水般散发号令。→ 发布有影响力的号召，开放资源，无咎。
  - 小象：王居无咎，正位也。
  - 爻位：五阳、当位、居中、与二爻无应（同性相敌）
  - 爻理：“涣汗其大号，涣王居，无咎”：王者之号至诚恳恻发号施令；如汗一出不返，足以通上下之壅塞、回周身之元气。
- 上九 涣其血，去逖出，无咎：离开伤害。→ 远离危险与伤害，不再陷入，无咎。
  - 小象：涣其血，远害也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“涣其血，去逖出，无咎”：“血”三说：血液；伤（王注），逖为远；以“涣其血”为句：涣其所伤而免于难；远害。

**走向**：聚拢转萃/节；不能聚则转涣的极致，陷入困。
