# 第42卦 益（巽上震下）· 增益受惠，宜趁势大作为

**卦辞**：利有攸往，利涉大川。
**彖传**：益，损上益下，民说无疆；自上下下，其道大光。利有攸往，中正有庆；利涉大川，木道乃行。益动而巽，日进无疆；天施地生，其益无方。凡益之道，与时偕行。
**大象**：风雷，益；君子以见善则迁，有过则改。
**态势**：上面主动施惠于下，资源、机会、支持在流向你；这是做大事、启动新计划的好窗口。
**像这样的事**：获得投资/扶持、政策红利、被提拔、团队得到资源、行业风口、他人给予机会。
**判断要点**：① 有外部或上级的实际支持；② 你有项目可以承接；③ 机会有时效。
**对策**
- 宜：趁势发力、善用资源、改过迁善、把好处转为长期能力、回报与分享。
- 忌：贪多、投机、拿资源去做不必要的事、受益后忘恩、挥霍。

**卦理**（据《周易译注》总论提炼）
- 《益》是减损于上，增益于下：如损墙上之土增墙基，则墙固（损上益下，益下固其本）。卦辞“利有攸往，利涉大川”。
- 下三爻受益：初九“利用为大作，元吉无咎”（要大有作为，不可安逸）；六二“十朋之龟，永贞吉”（长守中正）；六三“益之用凶事，无咎”（不辞辛劳施于救凶平险）。上三爻自损：六四“告公从，利用为依迁国”（依附尊者行益下）；九五“有孚惠心，勿问元吉”（真诚施惠天下）；上九“莫益之，或击之，立心勿恒，凶”（居高位不自损，求益无厌，被击）。
- 《损》与《益》互补：损下足以益上，上受益又当施惠于下；损上足以益下，下获惠亦可转益于上。更广义是利弊祸福交互变化：孔子读《损》《益》叹“自损者益，自益者缺”；利害之反，祸福之门户，不可不察。
**二体**：下震上巽；**互卦**：剥（二三四为下互，三四五为上互）

**六爻**
- 初九 利用为大作，元吉，无咎：利用受益大干一场。→ 起步就大胆但务必有成果，吉。
  - 小象：元吉无咎，下不厚事也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“利用为大作，元吉，无咎”：大作指耕播之事（虞翻、侯果）；下不厚事：居下不可承担厚事，必须元吉才无咎。
- 六二 或益之十朋之龟，弗克违，永贞吉，王用享于帝，吉：被厚赠。→ 不勉强，但以诚守正，会有持续助益。
  - 小象：或益之，自外来也。
  - 爻位：二阴、当位、居中、与五爻有应、乘刚（压在阳爻上）
  - 爻理：“或益之十朋之龟，弗克违，永贞吉，王用享于帝，吉”：与《损》六五同辞不同位：损六五居上受下益（君位元吉），益六二居下受上益（臣位永贞吉）。
- 六三 益之用凶事，无咎，有孚中行，告公用圭：把受益用于危难处。→ 用资源去解决困难，要以诚信公告。
  - 小象：益用凶事，固有之也。
  - 爻位：三阴、不当位、与上爻有应
  - 爻理：“益之用凶事，无咎，有孚中行，告公用圭”：不可无功受益，语意比初九更强，因六三失正又居多凶之位；中行、用圭：重申无咎之道。
- 六四 中行，告公从，利用为依迁国：居中通达。→ 作为联络人让双方信任，可做大迁移（转型）。
  - 小象：告公从，以益志也。
  - 爻位：四阴、当位、与初爻有应、承阳（托着上面的阳爻）
  - 爻理：“中行，告公从，利用为依迁国”：三、四皆不中，皆以“中行”为诫（或蔡渊说：在一卦之中）；益志。
- 九五 有孚惠心，勿问元吉，有孚惠我德：有诚信有恩惠。→ 心存善意施惠，不必问回报，必大吉。
  - 小象：有孚惠心，勿问之矣；惠我德，大得志也。
  - 爻位：五阳、当位、居中、与二爻有应
  - 爻理：“有孚惠心，勿问元吉，有孚惠我德”：《损》六五受下之益而元吉，《益》九五一心自损益下，只知民当益，勿问元吉。
- 上九 莫益之，或击之，立心勿恒，凶：无人益他，反有人攻击。→ 只想益己、不肯益人，反招攻击；要保持施惠的恒心。
  - 小象：莫益之，偏辞也；或击之，自外来也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“莫益之，或击之，立心勿恒，凶”：与《损》上九对照：损己益人之心终获益于人（得臣无家），损人益己之念反受损于人，被击罹凶。自损必益，自益必损。

**走向**：益得其用转恒/泰；益极而损则转夬/损。
