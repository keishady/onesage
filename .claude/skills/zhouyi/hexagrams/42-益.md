# 第42卦 益（巽上震下）· 增益受惠，宜趁势大作为

**卦辞**：利有攸往，利涉大川。
**态势**：上面主动施惠于下，资源、机会、支持在流向你；这是做大事、启动新计划的好窗口。
**像这样的事**：获得投资/扶持、政策红利、被提拔、团队得到资源、行业风口、他人给予机会。
**判断要点**：① 有外部或上级的实际支持；② 你有项目可以承接；③ 机会有时效。
**对策**
- 宜：趁势发力、善用资源、改过迁善、把好处转为长期能力、回报与分享。
- 忌：贪多、投机、拿资源去做不必要的事、受益后忘恩、挥霍。

**六爻**
- 初九 利用为大作，元吉，无咎：利用受益大干一场。→ 起步就大胆但务必有成果，吉。
- 六二 或益之十朋之龟，弗克违，永贞吉，王用享于帝，吉：被厚赠。→ 不勉强，但以诚守正，会有持续助益。
- 六三 益之用凶事，无咎，有孚中行，告公用圭：把受益用于危难处。→ 用资源去解决困难，要以诚信公告。
- 六四 中行，告公从，利用为依迁国：居中通达。→ 作为联络人让双方信任，可做大迁移（转型）。
- 九五 有孚惠心，勿问元吉，有孚惠我德：有诚信有恩惠。→ 心存善意施惠，不必问回报，必大吉。
- 上九 莫益之，或击之，立心勿恒，凶：无人益他，反有人攻击。→ 受益太多而不再施惠，会招祸，要保持恒心。

**走向**：益得其用转恒/泰；益极而损则转夬/损。
