# 第34卦 大壮（震上乾下）· 强盛有力，贵在守正克制

**卦辞**：利贞。
**彖传**：大壮，大者壮也。刚以动，故壮。大壮利贞，大者正也。正大而天地之情可见矣！
**大象**：雷在天上，大壮；君子以非礼弗履。
**态势**：你的力量正盛、势头很猛；但力气大不等于该用力，越强越要合礼、守正，否则会撞到栅栏上。
**像这样的事**：团队扩张期、实力占优的谈判、业绩暴涨、权力上升、血气方刚想硬干。
**判断要点**：① 你确实占优势；② 冲动与野心同时上升；③ 前方有看不见的"藩篱"（规则、底线、舆论）。
**对策**
- 宜：用力要合正道、先立规矩再扩大、强而不暴、留有余地、借势做正确的事。
- 忌：逞强、凭实力压人、不守规则、盲目冲进未知地带、把一时强势当永久。

**卦理**（据《周易译注》总论提炼）
- 《大壮》是大为强盛。卦辞“利贞”：守正处壮必吉。关键是不可恃强“用壮”，要谦退持中：二、四两阳以谦柔获吉（阳居阴位），初、三妄动必凶；五、上两阴刚壮已过，更宜柔和自守。“不用壮而弥壮”。
- 匹夫之勇不是大壮；自反而缩、理直气壮才是正。不由道而胜是小人用壮；由道而败是君子“用罔”。《易》多扶阳抑阴，唯《乾》和《大壮》戒人用阳太过。止戈为武：刚武强盛须建立在正的基础上，不得滥用。
**二体**：下乾上震；**互卦**：夬（二三四为下互，三四五为上互）

**六爻**
- 初九 壮于趾，征凶，有孚：脚趾壮硕就想远行。→ 只是局部强就急着出征，必凶。先稳住基本功。
  - 小象：壮于趾，其孚穷也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“壮于趾，征凶，有孚”：趾为动象，壮于趾是盛于进；阳刚初壮即动必凶，要守信不进，善养其壮（慎始）。
- 九二 贞吉：居中得正。→ 强盛时自守不进、不极其刚，保持中道，吉。
  - 小象：九二贞吉，以中也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“贞吉”：大壮之时愈要谦柔不用壮；阳居阴位者为吉（虑阳刚过壮）；二与四都说贞吉。
- 九三 小人用壮，君子用罔，贞厉，羝羊触藩，羸其角：小人逞勇，君子不用。→ 此时越用蛮力越卡，会被困住，克制。
  - 小象：小人用壮，君子罔也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“小人用壮，君子用罔，贞厉，羝羊触藩，羸其角”：三与上都在穷位有触藩之象；戒三不要因有应而逞壮被小人所用。
- 九四 贞吉，悔亡，藩决不羸，壮于大舆之輹：藩篱打开。→ 阻力消除，前进顺畅，借力而进。
  - 小象：藩决不赢，尚往也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“贞吉悔亡，藩决不羸，壮于大舆之輹”：二、四同以阳居阴；但二只是自守不进，四有可进之象（以阳居阴不极其刚，前遇二阴有藩决之象）。
- 六五 丧羊于易，无悔：在平易处丢掉羊。→ 放下刚猛的锋芒，以柔和方式化解，反而无悔。
  - 小象：丧羊于易，位不当也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）
  - 爻理：“丧羊于易，无悔”：位不当不只阴居阳，而是四阳已过，五所处非当壮之位，以柔中居之，所以丧羊于易（轻易放下刚壮）而无悔。
- 上六 羝羊触藩，不能退，不能遂，无攸利，艰则吉：进退两难。→ 硬冲到进退失据，只有在艰难中冷静才有出路。
  - 小象：不能退不能遂，不详也；艰则吉，咎不长也。
  - 爻位：上阴、当位、与三爻有应
  - 爻理：“羝羊触藩，不能退，不能遂，无攸利，艰则吉”：壮终动极无处可去，像羊角挂在藩上；盲目强进不利，守艰缓图则有吉。

**走向**：守正则转泰/恒；逞强则转遯/大过。
