# 第45卦 萃（兑上坤下）· 荟萃聚集，凝聚人心，防聚而生乱

**卦辞**：亨。王假有庙，利见大人，亨，利贞。用大牲吉，利有攸往。
**彖传**：萃，聚也。顺以说，刚中而应，故聚也。王假有庙，致孝享也；利见大人亨，聚以正也；用大牲吉利有攸往，顺天命也。观其所聚，而天地万物之情可见矣！
**大象**：泽上于地，萃；君子以除戎器，戒不虞。
**态势**：人、资源、想法在汇聚；要有共同的信仰/目标和核心领导，同时备好应对聚集带来的风险。
**像这样的事**：团队集结、大型活动、融资聚合、社群壮大、联盟形成、产业聚集。
**判断要点**：① 多方正在靠拢；② 需要核心与规则；③ 聚集规模扩大后暗藏风险。
**对策**
- 宜：确立共同目标、选贤任能、设立仪式与制度、慷慨投入、居安思危、防范突发事件。
- 忌：无核心、乌合之众、人多无纪律、忽视后勤与安全、聚而不用。

**卦理**（据《周易译注》总论提炼）
- 《萃》是会聚：方以类聚，物以群分。以人与人在政治关系中的相聚为喻。卦辞“亨，王假有庙，利见大人，亨利贞，用大牲吉”：君王必须以美德、正道聚合人神，会通上下；聚以正则利，顺天命则吉。
- 四阴求聚于人：初六位卑不可妄聚，专一孚诚；六二柔顺中正受尊者牵引得聚；六三失正无应，近比阳刚可往聚；上六穷居萃极，欲聚无门。四、五两阳获人来聚：九四不当位获三阴聚，须大吉才无咎；九五居尊尚未取信于众，当修“元永贞”之德。六爻无一凶，也无一完美顺畅，都系以“无咎”，无咎者善补过也：会聚之时稍一失正即生变乱。《大象》“除戎器，戒不虞”：长存戒防之心。
**二体**：下坤上兑；**互卦**：渐（二三四为下互，三四五为上互）

**六爻**
- 初六 有孚不终，乃乱乃萃；若号，一握为笑，勿恤，往无咎：初聚时信念不稳。→ 先稳住人心，必要时呼唤，不要被噪音干扰。
  - 小象：乃乱乃萃，其志乱也。
  - 爻位：初阴、不当位、与四爻有应
  - 爻理：“有孚不终，乃乱乃萃，若号，一握为笑，勿恤，往无咎”：咎在“疑”（疑四与三，志意迷乱）；疑消则往无咎而有笑。
- 六二 引吉，无咎，孚乃利用禴：引导而聚。→ 以诚心牵引，不夸饰，吉。
  - 小象：引吉无咎，中未变也
  - 爻位：二阴、当位、居中、与五爻有应
  - 爻理：“引吉，无咎，孚乃利用禴”：孚信长存，不变柔顺中正之志，诚心见引于尊者，薄祭（禴）也获享于神；诚素著白于幽明之际。
- 六三 萃如嗟如，无攸利，往无咎，小吝：想聚却叹息。→ 找不到可聚的对象时，主动去找更合适的人，小有遗憾。
  - 小象：往无咎，上巽也
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“萃如嗟如，无攸利，往无咎，小吝”：三与上无应又值穷位，一嗟一咨求萃不得；但天命不可不顺，若比四以萃五，虽位不当小吝，不能自外于会同之盟，故往无咎。
- 九四 大吉，无咎：为大聚奠基。→ 名位不够却聚了众人，要做出实绩才无咎，别越位；以大局为重，协调各方。
  - 小象：大吉无咎，位不当也
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“大吉，无咎”：失正未居尊位却广聚三阴，无尊位而得众心，必大吉而后可无咎（以吉补咎），如《益》初九必元吉而后无咎。
- 九五 萃有位，无咎，匪孚，元永贞：有位得聚。→ 位高者需要用德行巩固，而非仅靠权位，持续守正。
  - 小象：萃有位，志未光也
  - 爻位：五阳、当位、居中、与二爻有应
  - 爻理：“萃有位，无咎，匪孚，元永贞，悔亡”：有位而无德则虽萃而不使人信；不能单凭尊位，须修“元永贞”之德然后悔亡。
- 上六 赍咨涕洟，无咎：叹息流泪。→ 聚极而孤，反省不足，不要硬撑，可无咎。
  - 小象：赍咨涕洟，未安上也。
  - 爻位：上阴、当位、与三爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“赍咨涕洟，无咎”：萃极将散，欲聚无门；赍咨涕洟极言怨艾求萃之情，因忧惧知危而终得无咎。

**走向**：聚而有序转升；聚而无序转困/否。
