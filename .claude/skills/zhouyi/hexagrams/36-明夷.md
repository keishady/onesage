# 第36卦 明夷（坤上离下）· 光明受伤，韬光养晦

**卦辞**：利艰贞。
**彖传**：明入地中，明夷。内文明而外柔顺，以蒙大难，文王以之。利艰贞，晦其明也。内难而能正其志，箕子以之。
**大象**：明入地中，明夷；君子以莅众，用晦而明。
**态势**：环境黑暗，你有才华却被压制甚至被伤；此时要内明外晦，保全自己、守住信念，不要硬碰黑暗。
**像这样的事**：上司/环境压制人才、被误解或打压、有才难施展、在恶劣环境中求生、需隐藏锋芒。
**判断要点**：① 你清醒、有能力；② 上位者昏暗或环境不公；③ 暴露锋芒会被针对。
**对策**
- 宜：隐藏锋芒、内守正道、保存实力、寻找暗中盟友、忍耐并记录、必要时远走。
- 忌：公开硬顶、意气用事、失去底线、消极放弃自己。

**卦理**（据《周易译注》总论提炼）
- 《明夷》是光明受伤：明入地中，政治昏暗之世，君子自晦其明、守正不移。卦辞“利艰贞”：艰难中维护正道、等待重见光明。
- 五爻处明夷五种方式（苏轼）：力能救则救（六二用拯）；力能正则正（九三南狩，汤武式毅烈行动）；不能救不能正则忍辱守持、不敢辞辱以私便其身（六五箕子）；无责于斯世者，近则入腹获心出门庭（六四）、远则行不及食（初九）。初、四为消极反抗，二、三、五为积极救治。上六是暗君（不明晦）。
- 大旨都是艰贞守正：时世虽暗，道不可没，立身纯正则危不足忧（明不可息）。
**二体**：下离上坤；**互卦**：解（二三四为下互，三四五为上互）

**六爻**
- 初九 明夷于飞，垂其翼，君子于行，三日不食：飞着却垂下翅膀。→ 刚被打压就先自保，哪怕暂时吃苦也要走。
  - 小象：君子于行，义不食也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“明夷于飞，垂其翼，君子于行，三日不食，有攸往，主人有言”：垂翼而飞，君子远去，三日不食；如《诗》之兴体，前两句起兴后两句为所言；主人有言：不被理解。
- 六二 明夷，夷于左股，用拯马壮，吉：伤了大腿。→ 受伤后立刻借助有力之物（人脉/资源）求救，吉。
  - 小象：六二之吉，顺以则也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“夷于左股，用拯马壮，吉”：伤腿但用壮马拯救；比文王被囚羑里、散宜生献宝得脱；内文明而外柔顺以蒙大难。
- 九三 明夷于南狩，得其大首，不可疾贞：南方狩猎，抓到首恶。→ 有机会打击根源，但不要急，步骤稳。
  - 小象：南狩之志，乃大得也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“明夷于南狩，得其大首，不可疾贞”：汤起夏台、文王兴羑里，南狩得大首；正之不可急（不可疾）。
- 六四 入于左腹，获明夷之心，于出门庭：进入内心深处。→ 看清黑暗的核心后，及时离开其圈子。
  - 小象：入于左腹，获心意也。
  - 爻位：四阴、当位、与初爻有应、乘刚（压在阳爻上）
  - 爻理：“入于左腹，获明夷之心，于出门庭”：下三爻明在暗外，六四以柔正居暗地而尚浅，犹可得意远去：入腹获心而出门庭。
- 六五 箕子之明夷，利贞：箕子装疯。→ 在最险处内心保持光明、外表晦藏，坚守正道。
  - 小象：箕子之贞，明不可息也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）
  - 爻理：“箕子之明夷，利贞”：以柔中居暗地而已迫，内难正志、晦其明；“箕子”或指“孩子”（殷纣），说亦通；明不可息。
- 上六 不明晦，初登于天，后入于地：不明而晦暗。→ 黑暗者自己也会覆灭，不要同流，等待倾覆。
  - 小象：初登于天，照四国也；后入于地，失则也。
  - 爻位：上阴、当位、与三爻有应
  - 爻理：“不明晦，初登于天，后入于地”：上六极暗，自伤其明以至于暗，又伤他人之明；不曰“明夷”而曰“不明晦”：它不明而晦，所以五爻之明皆被其所夷。

**走向**：熬过去转家人（回归内部）/晋；若自己也同流则转坎。
