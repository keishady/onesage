# 第27卦 颐（艮上震下）· 颐养，慎言语、节饮食、养自己与养他人

**卦辞**：贞吉。观颐，自求口实。
**彖传**：颐，贞吉，养正则吉也。观颐，观其所养也；自求口实，观其自养也。天地养万物，圣人养贤以及万民。颐之时大矣哉！
**大象**：山下有雷，颐；君子以慎言语，节饮食。
**态势**：事情的关键在"养"——如何获取营养、如何养人、如何管住自己的嘴和欲望；吃什么、养谁，决定结果。
**像这样的事**：健康管理、养团队/养客户、选择收入来源、话多招祸、基础建设期、培养人才。
**判断要点**：① 重点是"滋养与供给"；② 你在选择养什么/被谁养；③ 要警惕被利益驱使而失正。
**对策**
- 宜：选正道养自己、观察别人如何自养、节制言语与饮食、扶植基础、可持续供给。
- 忌：贪食/贪利、依赖不正的来源、颠倒本末、胡说八道招祸。

**卦理**（据《周易译注》总论提炼）
- 《颐》是颐养：卦辞“贞吉。观颐，自求口实”：守正则吉，要观察所养所求。核心：自养当本于德，不可弃德求欲；养人当出于公，养德及物。
- 下三爻皆自养不得其道：初凶、二征凶、三十年勿用无攸利；上三爻皆养人：四吉、五居贞吉、上由颐厉吉利涉大川。公而大者吉，私而小者凶。立足点仍未偏离物质基础（自求口实），与“民以食为天”可勾联。
**二体**：下震上艮；**互卦**：坤（二三四为下互，三四五为上互）

**六爻**
- 初九 舍尔灵龟，观我朵颐，凶：放弃自己的宝贵，羡慕别人。→ 别眼红他人而丢掉自己的优势。
  - 小象：观我朵颐，亦不足贵也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“舍尔灵龟，观我朵颐，凶”：虽有刚阳，仍动欲垂涎羡人之养；下卦属动、上卦属止，在下而动者求养于人，累于口体。
- 六二 颠颐，拂经，于丘颐，征凶：颠倒求养。→ 靠别人供养或走歪路，不吉，回到自立。
  - 小象：六二征凶，行失类也
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“颠颐，拂经于丘，征凶”：句读两说：以“拂经于丘”为句（违常于五）；或“颠颐拂经”为句（求养于初则颠倒违理，求养于上则往而凶）；行失类。
- 六三 拂颐，贞凶，十年勿用，无攸利：违背养之道。→ 欲望失控，无利，长期难用。
  - 小象：十年勿用，道大悖也。
  - 爻位：三阴、不当位、与上爻有应
  - 爻理：“拂颐，贞凶，十年勿用，无攸利”：求养行为极不正，但仍勉其自反；戒之也。
- 六四 颠颐，吉；虎视眈眈，其欲逐逐，无咎：以上养下，目光专注。→ 有志向有欲望但目标正当，吉。
  - 小象：颠颐之吉，上施光也。
  - 爻位：四阴、当位、与初爻有应
  - 爻理：“颠颐，吉，虎视眈眈，其欲逐逐，无咎”：与二同称颠颐，二志在物故凶，四志在道故吉；上施光，含取于民用于民的微旨。
- 六五 拂经，居贞吉，不可涉大川：违常但守静。→ 力量不足时不要冒险，守成吉。
  - 小象：居贞之吉，顺以从上也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“拂经，居贞吉，不可涉大川”：居尊而才德薄弱，己身无法自养，须依赖上九贤者；顺以从上；因尚有养天下之心，居贞则吉。
- 上九 由颐，厉吉，利涉大川：众人由你得养。→ 你是供养核心，责任重，谨慎，可成大事。
  - 小象：由颐厉吉，大有庆也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“由颐，厉吉，利涉大川”：天下由之以颐，与《豫》九四“由豫，大有得”相对：大有庆。

**走向**：颐养得宜转复/益；若失养则转大过。
