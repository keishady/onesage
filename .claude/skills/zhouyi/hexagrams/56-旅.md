# 第56卦 旅（离上艮下）· 羁旅在外，寄人篱下，谨慎低调

**卦辞**：小亨，旅贞吉。
**彖传**：旅，小亨，柔得中乎外而顺乎刚，止而丽乎明，是以小亨，旅贞吉也。旅之时义大矣哉！
**大象**：山上有火，旅；君子以明慎用刑而不留狱。
**态势**：你处在陌生环境、没有根基，像旅人一样；能做的是小事，守正、柔和、谨慎，不要逞强。
**像这样的事**：外派/出差、初到新城市、新公司没根基、创业者在外拓展、临时合作、异地生活。
**判断要点**：① 你不是"主场"；② 资源和关系有限；③ 一言一行都被看着。
**对策**
- 宜：谦逊随和、少树敌、守本分、做好小事、保持警觉、保管好资财、留意口碑。
- 忌：摆架子、争执、轻易交底、贪多贪大、轻信陌生人、冒进。

**卦理**（据《周易译注》总论提炼）
- 《旅》专明行旅之理：亲寡旅也，旅而无所容：羁旅孤独愁郁。卦辞“小亨，旅贞吉”：守正，以柔顺持中为本。
- 凡阴柔中顺皆吉，卑屈者反戒；凡阳刚高亢皆危，穷骄者最凶。范仲淹：旅人之志，卑则自辱，高则见嫉，能执其中可谓智：初“琐琐”、四“不快”处二体之下卑以自辱；三“焚次”、上“焚巢”据二体之上高而见嫉；二“怀资”、五“誉命”柔而不失其中。广言之：诸侯寄寓、大夫去乱、圣贤周游，乃至天地万物之逆旅；旅之时义大矣哉。
**二体**：下艮上离；**互卦**：大过（二三四为下互，三四五为上互）

**六爻**
- 初六 旅琐琐，斯其所取灾：斤斤计较。→ 在外自甘卑琐、小气、过度计较，自招祸患。
  - 小象：旅琐琐，志穷灾也。
  - 爻位：初阴、不当位、与四爻有应
  - 爻理：“旅琐琐，斯其所取灾”：斯：此（帛书）；或斯贱之役；或“斯”解为“离”（离其所欲应四）；总之卑琐取灾。
- 六二 旅即次，怀其资，得童仆，贞：住进客店带着钱。→ 有安身之所、有资源、有可靠帮手，守正。
  - 小象：得童仆贞，终无尤也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“旅即次，怀其资，得童仆贞”：柔顺中正有次、有资、有仆：内不失己，外不失人，旅所恃者皆全。
- 九三 旅焚其次，丧其童仆，贞厉：客店着火，失去仆人。→ 在外高傲刚愎，失去支持，危险。
  - 小象：旅焚其次，亦以伤矣；以旅与下，其义丧也。
  - 爻位：三阳、当位、与上爻无应（同性相敌）
  - 爻理：“旅焚其次，丧其童仆，贞厉”：刚亢不中；居刚用刚平时犹不可况旅；位愈高刚愈亢祸愈深（三焚次、上焚巢）。
- 九四 旅于处，得其资斧，我心不快：有立足点却不踏实。→ 有了一点资源但心里不安，不能松懈。
  - 小象：旅于处，未得位也；得其资斧，心未快也
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“旅于处，得其资斧，我心不快”：阳刚皆胜阴柔，唯旅不然；四虽得其处，仅足安身，岂得尽遂其志。
- 六五 射雉，一矢亡，终以誉命：射雉丢一箭。→ 小小损失换来声誉与任命，值得。
  - 小象：终以誉命，上逮也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“射雉，一矢亡，终以誉命”：柔得中乎外而顺乎刚；不取君象，有文明之德则令誉升闻、爵命之。
- 上九 鸟焚其巢，旅人先笑后号咷，丧牛于易，凶：先笑后哭。→ 在外骄傲大意，失去根基，凶。
  - 小象：以旅在上，其义焚也；丧牛于易，终莫之闻也。
  - 爻位：上阳、不当位、与三爻无应（同性相敌）
  - 爻理：“鸟焚其巢，旅人先笑后号咷，丧牛于易，凶”：以穷高为乐，先笑后号咷，与《同人》九五（先号咷而后笑）相反；阮籍：同人先号思其终，旅上之笑乐其穷。

**走向**：谨守则转渐/小过；骄纵则转丰后的衰。
