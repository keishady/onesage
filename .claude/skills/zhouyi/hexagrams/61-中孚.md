# 第61卦 中孚（巽上兑下）· 内心诚信，感而相通

**卦辞**：豚鱼吉，利涉大川，利贞。
**彖传**：中孚，柔在内而刚得中；说而巽，孚乃化邦也。豚鱼吉，信及豚鱼也；利涉大川，乘木舟虚也；中孚以利贞，乃应乎天也。
**大象**：泽上有风，中孚；君子以议狱缓死。
**态势**：靠真诚的信任把事办成，连最难感化的（豚鱼）也能打动；诚信是穿越风险的最强基础。
**像这样的事**：建立信任、长期合作、师生/亲子/夫妻、合伙创业、危机中的关系、品牌声誉。
**判断要点**：① 关系的基础是诚信；② 双方都有诚意；③ 外部环境险但可渡。
**对策**
- 宜：言行一致、坦诚相见、守诺、用诚意感化、以信立业。
- 忌：口惠而实不至、虚伪、轻易承诺、过度依赖信任而不设规则。

**卦理**（据《周易译注》总论提炼）
- 《中孚》是中心诚信：孔子反复以信德施教（敬事而信、主忠信、人而无信不知其可）。卦辞“豚鱼吉，利涉大川，利贞”：诚信广被微物（信及豚鱼），利涉险、利守正。
- 初安于下位以守信（虞吉）；二笃诚中实以感物（鸣鹤在阴，其子和之）；四专心致诚不贰（月几望，马匹亡）；五广施诚信而居尊（有孚挛如）：四正面；六三居心不诚言行无常（得敌，或鼓或罢或泣或歌）、上九信衰诈起虚声远闻（翰音登于天）：两反面。二、五最受推崇。九五“取信于民”：至诚动于内，万民必应而感移，尧舜之诚感于万国。大象“议狱缓死”。
**二体**：下兑上巽；**互卦**：颐（二三四为下互，三四五为上互）

**六爻**
- 初九 虞吉，有它不燕：安守一心则吉。→ 专一于自己的诚信对象，被其他东西诱惑就失去安宁。
  - 小象：初九虞吉，志未变也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“虞吉，有它不燕”：初九处勿用之位，慎守诚信无所求必吉；安处于下不假它求。
- 九二 鸣鹤在阴，其子和之；我有好爵，吾与尔靡之：鹤鸣子和。→ 真诚的心会引发共鸣，愿意分享成果。
  - 小象：其子和之，中心愿也。
  - 爻位：二阳、不当位、居中、与五爻无应（同性相敌）
  - 爻理：“鸣鹤在阴，其子和之，我有好爵，吾与尔靡之”：爻辞似《诗》：句式整齐、偶句谐韵、比兴；爱出者爱反，福往者福来；中心愿也。
- 六三 得敌，或鼓或罢，或泣或歌：遇到对手情绪起伏。→ 内心无主，被外界牵着走，需稳住。
  - 小象：或鼓或罢，位不当也。
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）
  - 爻理：“得敌，或鼓或罢，或泣或歌”：不当位自树其敌；人心不诚私念杂起，多方钻营，言行无常，徒劳无益。
- 六四 月几望，马匹亡，无咎：舍弃同类、专心向上。→ 放弃小圈子，专心靠近真正的核心，无咎。
  - 小象：马匹亡，绝类上也。
  - 爻位：四阴、当位、与初爻有应、承阳（托着上面的阳爻）
  - 爻理：“月几望，马匹亡，无咎”：禀阴顺之德，诚信必须专一；六四须绝初才能承五（马匹亡：绝类上）；孚不容于有二。
- 九五 有孚挛如，无咎：以诚信紧紧连结。→ 以诚信凝聚众人，无咎。
  - 小象：有孚挛如，位正当也。
  - 爻位：五阳、当位、居中、与二爻无应（同性相敌）
  - 爻理：“有孚挛如，无咎”：孚乃化邦；六爻不言孚，唯九五言之，九五是孚之主。
- 上九 翰音登于天，贞凶：声音飞上天，实质没跟上。→ 只有名声没有实质，信用破产，凶。
  - 小象：翰音登于天，何可长也！
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“翰音登于天，贞凶”：九二鸣鹤在阴实、上九飞鸣登天虚，道相反：虚声远闻而无实。

**走向**：诚信不变转益/既济；名过其实则转小过。
