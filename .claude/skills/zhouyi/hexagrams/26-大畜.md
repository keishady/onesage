# 第26卦 大畜（艮上乾下）· 大积蓄，厚积薄发

**卦辞**：利贞，不家食吉，利涉大川。
**彖传**：大畜，刚健笃实，辉光日新其德。刚上而尚贤，能止健，大正也。不家食吉，养贤也。利涉大川，应乎天也
**大象**：天在山中，大畜；君子以多识前言往行，以畜其德。
**态势**：能力、资源、学识大量积累，被阻止（止）住要先蓄力；一旦蓄足，就应出去做事而不是闭门自守。
**像这样的事**：长期学习、积累资金与技术、等待厚积薄发的节点、准备大型转型、培养人才。
**判断要点**：① 你已有一定积累；② 有某种力量在阻止你现在就出手；③ 蓄满之后有大机会。
**对策**
- 宜：持续积累、深耕专业、读书学习、蓄势待发、选择时机后果断出山。
- 忌：急于变现、半途而废、守着积累不敢用、闭门造车。

**卦理**（据《周易译注》总论提炼）
- 《大畜》是大为畜聚刚健正气：君子广畜美德，君王遍聚贤者。卦辞“利贞，不家食吉，利涉大川”：守正、养贤。
- 六爻三层：初、二为阳刚被畜，要先自畜其德，不宜躁进：初九有厉利已、九二舆说輹；四、五尊者畜下，规正制约健者：六四童牛之牿元吉，六五豮豕之牙吉；三与上为畜极而通：九三良马逐，上九何天之衢，亨。三虽畜极仍须艰贞，上九是大畜最完美的象征：自身盛美，天下贤路大开（刚上而尚贤）。
- 内卦受畜以“自止”为义，外卦能畜以“止之”为义（胡炳文）。
**二体**：下乾上艮；**互卦**：归妹（二三四为下互，三四五为上互）

**六爻**
- 初九 有厉，利已：有危险就停。→ 此时行动有危，克制，先蓄力。
  - 小象：有厉利已，不犯灾也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“有厉，利已”：阳刚居下被畜止，接受规正、自畜待时；知危不前则利。
- 九二 舆说輹：车脱了轴。→ 主动卸下动力，保存实力，等时机。
  - 小象：与说，中无尤也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“舆说輹”：自卸车轴缚、缓进畜德，无尤；《小畜》九三“舆说辐”是与人冲突、夫妻反目：脱辐在人，脱輹在己。
- 九三 良马逐，利艰贞，曰闲舆卫，利有攸往：良马驰骋。→ 此时可以前进，但要日日练习、防护好。
  - 小象：利有攸往，上合志也。
  - 爻位：三阳、当位、与上爻无应（同性相敌）
  - 爻理：“良马逐，利艰贞，曰闲舆卫，利有攸往”：与上九不相畜而志同，大路宽畅让良马奔逐；要不忘艰贞，日日练习车马防卫。
- 六四 童牛之牿，元吉：给小牛加护具。→ 在问题刚冒头时就加以约束，成本小而效果大。
  - 小象：六四元吉，有喜也。
  - 爻位：四阴、当位、与初爻有应、乘刚（压在阳爻上）
  - 爻理：“童牛之牿，元吉”：牛角未长先绑横木，止恶于未萌，用力少而易；五则阳已进而止之则难。
- 六五 豮豕之牙，吉：阉猪之牙。→ 化解对手的攻击性，不靠强压而靠釜底抽薪。
  - 小象：六五之吉，有庆也。
  - 爻位：五阴、不当位、居中、与二爻有应、承阳（托着上面的阳爻）
  - 爻理：“豮豕之牙，吉”：猪去势则牙不为害；知恶不可力制，察其机、塞其本原，不假严刑而恶自止。
- 上九 何天之衢，亨：通达天路。→ 积蓄到顶，一路通畅，大展宏图。
  - 小象：何天之衢，道大行也。
  - 爻位：上阳、不当位、与三爻无应（同性相敌）
  - 爻理：“何天之衢，亨”：“何”字三说：语气词（更何所畜，畜极已通）；训当、担当（荷）；衍字。三说皆通，大意畜极而通，道大行。

**走向**：蓄极则发，转泰；若一味积累不行动则转颐/大过。
