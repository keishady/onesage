# 第21卦 噬嗑（离上震下）· 咬合障碍，果断排除阻碍

**卦辞**：亨。利用狱。
**彖传**：颐中有物，曰噬嗑。噬嗑而亨，刚柔分，动而明，雷电合而章。柔得中而上行，虽不当位，利用狱也。
**大象**：雷电，噬嗑；先王以明罚敕法。
**态势**：中间有东西卡住（小人、违规、障碍），必须咬断、清除；用明察（离）加雷霆（震）来处理，赏罚要分明。
**像这样的事**：处理违规、清除内鬼、解决顽固障碍、执行制度、追责、争取合法权益。
**判断要点**：① 障碍是明确可识别的；② 对方有错或违规；③ 不处理会影响全局。
**对策**
- 宜：明辨事实、依规办事、先易后难逐步咬合、刚柔并济、适度惩戒。
- 忌：滥用权力、因情绪过度惩罚、只做表面文章、拖延不决。

**卦理**（据《周易译注》总论提炼）
- 《噬嗑》以口中咬合食物为喻，讲用刑：卦辞“亨，利用狱”。初、上两阳是受罚者：初犯能改无咎，上九积罪深重凶；二至五是施刑者：二为吏、三为吏、四为卿、五为君；六二以柔乘刚，三、五阴处阳位，四阳处阴位，体现刚柔相济。
- 治狱艰难：各爻都有咎、吝、艰、厉，朱熹说治人必为敌，须以艰难正固处之。最能体现全卦大义的是柔中居尊的六五：用刑期于无刑，立于刚严而本于文明；火雷之象，明罚敕法，以柔中为主，不失辟以止辟。
**二体**：下震上离；**互卦**：蹇（二三四为下互，三四五为上互）

**六爻**
- 初九 屦校灭趾，无咎：脚被镣铐，小惩。→ 对初犯小错及时轻罚，防止升级。
  - 小象：屡校灭趾，不行也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“屡校灭趾，无咎”：小惩大诫，小人之福；不戚不惩。
- 六二 噬肤灭鼻，无咎：咬软肉太用力。→ 问题易处理，但用力过猛会伤自己，拿捏分寸。
  - 小象：噬肤灭鼻，乘刚也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“噬肤灭鼻，无咎”：乘凌刚强，不可纯柔，要以刚严济柔中，刑刚强之人必须深痛。
- 六三 噬腊肉，遇毒，小吝，无咎：硬肉有毒。→ 处理久积的难题会有麻烦；名分、权限未正就匆忙动手，更易惹祸，小有困窘，仍可行。
  - 小象：遇毒，位不当也。
  - 爻位：三阴、不当位、与上爻有应、承阳（托着上面的阳爻）
  - 爻理：“噬腊肉，遇毒，小吝，无咎”：位不当就匆匆施刑，则遇毒；治狱必先正位才能服众。
- 九四 噬干胏，得金矢，利艰贞，吉：骨肉难咬。→ 难题要坚持，找到关键证据/突破口，艰难中得吉。
  - 小象：利艰贞吉，未光也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“噬干胏，得金矢，利艰贞，吉”：不中失正与六三同，施刑难顺畅；但刚直不阿，在艰难中守正则吉；未光，未尽通理。
- 六五 噬干肉，得黄金，贞厉，无咎：处理关键问题得宝。→ 居中公正决断，保持警惕，成果大。
  - 小象：贞厉无咎，得当也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“噬干肉，得黄金，贞厉，无咎”：阴处阳位却得中，得当：九四以刚噬为有司执法之公，六五以柔噬为人君不忍之仁。
- 上九 何校灭耳，凶：枷锁盖过耳朵。→ 屡教不改者、冥顽不化，后果严重，必须承担。
  - 小象：何校灭耳，聪不明也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“何校灭耳，凶”：积恶遭灭；与初九“屡校灭趾”对照：小惩大诫 vs 积恶而不可解。善不积不足以成名，恶不积不足以灭身。

**走向**：障碍清除则转颐（养）；若处理不当则转困。
