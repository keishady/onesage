# 第23卦 剥（艮上坤下）· 剥落衰败，小人得势，宜顺势止损

**卦辞**：不利有攸往。
**彖传**：剥，剥也，柔变刚也。不利有攸往，小人长也。顺而止之，观象也。君子尚消息盈虚，天行也。
**大象**：山附于地，剥；上以厚下安宅。
**态势**：下面的阴不断侵蚀上面仅剩的阳，根基被一点点剥落；此时不宜出击扩张，而要保存、止损、守住最后的根本。
**像这样的事**：业务持续下滑、团队流失、被蚕食的市场份额、关系渐渐破裂、资源枯竭。
**判断要点**：① 趋势是持续下降而非偶发；② 外部力量增强、内部力量减弱；③ 硬撑只会消耗更多。
**对策**
- 宜：收缩战线、保全核心、顺势而止、保留火种、等待转机、避免大型投入。
- 忌：逆势大举扩张、与小人正面硬碰、抱幻想拖延、把最后的资本赌上。

**卦理**（据《周易译注》总论提炼）
- 《剥》是阴剥落阳：如秋气萧瑟万物零落。卦辞“不利有攸往”：此时宜谨慎居守，把握转剥复阳之机；剥极必复，顺势止剥。
- 六爻五阴一阳：以床为喻——初六剥床足，六二剥床辨（床头与足之间），尚未致危但要守正；六四剥床以肤（剥至床面，切近灾）凶；六三剥之无咎（与上九有应，含阳）；六五贯鱼以宫人宠（承刚，无不利）。上九硕果不食，一阳独存、剥而不尽，终将回复。
- 硕果不食，是核、是仁、是生生之根：自然与社会生生不息，唯有君子的阳刚才能使它萌发。但“小人剥庐”也设危辞示诫。
**二体**：下坤上艮；**互卦**：坤（二三四为下互，三四五为上互）；全卦仅一阳（上爻），常视为卦主

**六爻**
- 初六 剥床以足，蔑贞凶：床脚被剥蚀。→ 问题已从根基开始，及时纠偏，否则越来越糟。
  - 小象：剥床以足，以灭下也。
  - 爻位：初阴、不当位、与四爻无应（同性相敌）
  - 爻理：“剥床以足，蔑贞凶”：床足在下，先从下剥，渐及于上，则君政崩灭。
- 六二 剥床以辨，蔑贞凶：剥到床板。→ 局面进一步恶化，别硬扛，寻求支持。
  - 小象：剥床以辨，未有与也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）
  - 爻理：“剥床以辨，蔑贞凶”：无应无与，只能防凶；上有阳刚相助才能抑剥。
- 六三 剥之，无咎：脱离剥落者。→ 离开不对的伙伴/环境，可无咎。
  - 小象：剥之无咎，失上下也。
  - 爻位：三阴、不当位、与上爻有应
  - 爻理：“剥之无咎”：群阴皆剥阳，唯三独应上九，无剥害意，失上下（离开同类阴）所以无咎。
- 六四 剥床以肤，凶：灾祸切身。→ 已伤到自身，需要迅速抽身自保。
  - 小象：剥床以肤，切近灾也。
  - 爻位：四阴、当位、与初爻无应（同性相敌）
  - 爻理：“剥床以肤，凶”：床体已剥尽，切近灾；但剥至极则复元转机也随之而来，六五无不利即其苗头。
- 六五 贯鱼，以宫人宠，无不利：众阴听命于一阳。→ 整合剩余力量，团结听命，反败为利。
  - 小象：以宫人宠，终无尤也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“贯鱼，以宫人宠，无不利”：取周宫嫔制度喻——宫人依次承侍，一个跟着一个，由后率之；率群阴承阳，终无尤。
- 上九 硕果不食，君子得舆，小人剥庐：硕果仅存。→ 保住最后的根本，不吃掉，保留种子，君子得到承载。
  - 小象：君子得舆，民所载也；小人剥庐，终不可用也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“硕果不食，君子得舆，小人剥庐”：剥尽复来，君子有为之时；小人剥庐（自毁居所），特设危辞。

**走向**：剥极必复，下一步转复（回春）；若处理不当则转坤（全部消散）。
