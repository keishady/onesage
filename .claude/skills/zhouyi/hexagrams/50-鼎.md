# 第50卦 鼎（离上巽下）· 鼎新立业，聚贤成器，稳重承载

**卦辞**：元吉，亨。
**态势**：破旧之后建立新秩序，像用鼎烹饪（养贤），要靠选人、聚才、稳定的制度来承载大事。
**像这样的事**：新体系成立、组建核心团队、建立品牌/制度、新旧交替后的稳定、重用人才。
**判断要点**：① 旧局已变；② 你要承载新事业；③ 成败取决于鼎足是否稳、盛的内容是否有价值。
**对策**
- 宜：选好人、用好才、制度稳重、聚焦价值、名实相符、饮食（资源）要精。
- 忌：用人不当、基础不稳就急于挑大梁、徒有名声、独占成果。

**六爻**
- 初六 鼎颠趾，利出否，得妾以其子，无咎：鼎足倒翻，倒出旧渣。→ 顺势清掉旧弊，重新开始，无咎。
- 九二 鼎有实，我仇有疾，不我能即，吉：鼎中有实。→ 有了真实内容，小人想攀附也靠不近，稳吉。
- 九三 鼎耳革，其行塞，雉膏不食，方雨亏悔，终吉：鼎耳坏了。→ 暂时无法发挥价值，沟通渠道有问题，耐心修复，终吉。
- 九四 鼎折足，覆公餗，其形渥，凶：鼎足折断，汤倾覆。→ 用人不当导致失败，责任重大，必须检讨。
- 六五 鼎黄耳金铉，利贞：鼎耳金黄。→ 居中守正，沟通渠道得宜，利。
- 上九 鼎玉铉，大吉，无不利：鼎玉饰。→ 既刚且柔，成熟完美，大吉。

**走向**：鼎立则转大有/既济；用人失当则转否。
