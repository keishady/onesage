# 第50卦 鼎（离上巽下）· 鼎新立业，聚贤成器，稳重承载

**卦辞**：元吉，亨。
**彖传**：鼎，象也，以木巽火，亨饪也。圣人亨以享上帝，而大亨以养圣贤。巽而耳目聪明，柔进而上行，得中而应乎刚，是以元亨。
**大象**：木上有火，鼎；君子以正位凝命。
**态势**：破旧之后建立新秩序，像用鼎烹饪（养贤），要靠选人、聚才、稳定的制度来承载大事。
**像这样的事**：新体系成立、组建核心团队、建立品牌/制度、新旧交替后的稳定、重用人才。
**判断要点**：① 旧局已变；② 你要承载新事业；③ 成败取决于鼎足是否稳、盛的内容是否有价值。
**对策**
- 宜：选好人、用好才、制度稳重、聚焦价值、名实相符、饮食（资源）要精。
- 忌：用人不当、基础不稳就急于挑大梁、徒有名声、独占成果。

**卦理**（据《周易译注》总论提炼）
- 《鼎》是烹饪之器与权力法器：烹物化生为熟，喻调剂成新，侧重行使权力、经济天下、自新新人。杂卦：革去故也，鼎取新也。卦辞“元吉亨”。大象“正位凝命”：端正居位、严守使命。
- 六爻各取鼎的部位：初六颠趾利出否（倒鼎清废物，得妾以其子）无咎；九二鼎有实（我仇有疾，不我能即）吉；九三鼎耳革（其行塞，雉膏不食，方雨亏悔终吉）；九四鼎折足覆公餗（任非其人，凶）；六五鼎黄耳金铉利贞；上九鼎玉铉大吉无不利。全卦只九四是反面，董仲舒：任非其人而国家不倾者自古未闻。
- 核心：鼎的功用与新制之立，必须依赖多方面纯正、坚实力量的协心撑持。
**二体**：下巽上离；**互卦**：夬（二三四为下互，三四五为上互）

**六爻**
- 初六 鼎颠趾，利出否，得妾以其子，无咎：鼎足倒翻，倒出旧渣。→ 顺势清掉旧弊，重新开始，无咎。
  - 小象：鼎颠趾，未悖也；利出否，以从贵也。
  - 爻位：初阴、不当位、与四爻有应、承阳（托着上面的阳爻）
  - 爻理：“鼎颠趾，利出否，得妾以其子，无咎”：现象似违常规，烹物成新之时实不悖义理；凡事迹虽悖上下尊卑之序，于义则无咎。
- 九二 鼎有实，我仇有疾，不我能即，吉：鼎中有实。→ 有了真实内容，小人想攀附也靠不近，稳吉。
  - 小象：鼎有实，慎所之也；我仇有疾，终无尤也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“鼎有实，我仇有疾，不我能即，吉”：刚中德美，慎行不偏故吉；与九四失位不中、力不胜任反衬。
- 九三 鼎耳革，其行塞，雉膏不食，方雨亏悔，终吉：鼎耳坏了。→ 暂时无法发挥价值，沟通渠道有问题，耐心修复，终吉。
  - 小象：鼎耳革，失其义也。
  - 爻位：三阳、当位、与上爻无应（同性相敌）
  - 爻理：“鼎耳革，其行塞，雉膏不食，方雨亏悔，终吉”：以阴阳调和之雨为象，勉其改刚亢之性，恢复虚中之宜，鼎耳不革、其行不塞，则雉膏必可食，悔消终吉。
- 九四 鼎折足，覆公餗，其形渥，凶：鼎足折断，汤倾覆。→ 用人不当导致失败，责任重大，必须检讨。
  - 小象：覆公馀，信如何也！
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“鼎折足，覆公餗，其形渥，凶”：力不胜任，任非其人则国家倾；“形渥”即“刑剧”（重刑）通用，及于刑辟（帛书作“刑屋”）；信如何也。
- 六五 鼎黄耳金铉，利贞：鼎耳金黄。→ 居中守正，沟通渠道得宜，利。
  - 小象：鼎黄耳，中以为实也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“鼎黄耳金铉，利贞”：金铉或指上九；铉所以举鼎，必在耳上；“金象以九爻取，玉象以爻位刚柔相济取”。
- 上九 鼎玉铉，大吉，无不利：鼎玉饰。→ 既刚且柔，成熟完美，大吉。
  - 小象：玉铉在上，刚柔节也。
  - 爻位：上阳、不当位、与三爻无应（同性相敌）
  - 爻理：“鼎玉铉，大吉，无不利”：阳刚在上，鼎用昭著，举鼎功成；《井》《鼎》皆以上爻为吉：水汲出井为用，食烹出鼎为用。

**走向**：鼎立则转大有/既济；用人失当则转否。
