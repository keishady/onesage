# 第2卦 坤（坤上坤下）· 柔顺承载，厚德载物

**卦辞**：元亨，利牝马之贞。君子有攸往，先迷后得主，利西南得朋，东北丧朋。安贞吉。
**彖传**：至哉坤元！万物资生，乃顺承天。坤厚载物，德合无疆；含弘光大，品物咸亨。牝马地类，行地无疆，柔顺利贞。君子攸行，先迷失道，后顺得常。西南得朋，乃与类行；东北丧朋，乃终有庆。安贞之吉，应地无疆。
**大象**：地势坤；君子以厚德载物。
**态势**：你不是主导者，适合配合、承载、服务、积累；顺势而为比逞强更有收获。
**像这样的事**：新人进团队、辅佐领导、做执行与支持、承接大项目的一环、需要耐心积累的长期工程。
**判断要点**：① 局面由别人（或大环境）主导；② 你的价值在于做实、做稳、把事承住；③ 抢先出头反而吃亏。
**对策**
- 宜：先跟随再得主、脚踏实地、包容、多结盟友、把基础打牢。
- 忌：越位抢功、固执己见、过于被动不表态、一味退让丧失原则。

**六爻**
- 初六 履霜，坚冰至：见到微小的坏苗头。→ 防微杜渐，早处理小问题，别等坚冰。
  - 小象：履霜坚冰，阴始凝也；驯致其道，至坚冰也。
- 六二 直方大，不习无不利：正直、方正、宽厚，自然成事。→ 守本分、做实事，不必刻意讨巧。
  - 小象：六二之动，直以方也；不习无不利，地道光也。
- 六三 含章可贞，或从王事，无成有终：有才不炫，辅助成事。→ 把功劳归团队，低调做事，终有成。
  - 小象：含章可贞，以时发也；或从王事，知光大也。
- 六四 括囊，无咎无誉：如扎紧口袋，谨言慎行。→ 局势敏感时少说话、不站队、不出头。
  - 小象：括囊无咎，慎不害也
- 六五 黄裳，元吉：居中守柔，美德内蕴。→ 以谦和稳重处高位，不张扬。
  - 小象：黄裳元吉，文在中也。
- 上六 龙战于野，其血玄黄：阴盛至极，与阳相争两败。→ 别和对手硬碰，见好就收，及时抽身。
  - 小象：龙战于野，其道穷也。
- 用六 利永贞：六爻皆动时用。→ 柔顺到极处，要持久守正，不因顺从而丧失原则。
  - 小象：用六永贞，以大终也。

**走向**：积累厚了自然转乾（有能力主导）；若一味退让则被边缘化。
