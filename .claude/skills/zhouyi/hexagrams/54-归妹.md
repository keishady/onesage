# 第54卦 归妹（震上兑下）· 名分未正，因情而动，需谨慎

**卦辞**：征凶，无攸利。
**彖传**：归妹，天地之大义也。天地不交，而万物不兴；归妹，人之终始也。说以动，所归妹也；征凶，位不当也；无攸利，柔乘刚也。
**大象**：泽上有雷，归妹；君子以永终知蔽。
**态势**：因一时情绪或利益而结合/行动，名分不正、位置不当；此时贸然前进不利，要先摆正关系和位置。
**像这样的事**：关系名分不清、被迫的婚姻/合作、位置尴尬的角色、不对等的交易、感情冲动下的决定。
**判断要点**：① 关系或位置不匹配；② 行动由情绪或利益驱动；③ 对方不一定能给你承诺。
**对策**
- 宜：先明确名分与规则、保持低姿态、小心被利用、做好备份与退路。
- 忌：冲动入局、期待不对等的关系有好结果、占位不当、轻信承诺。

**卦理**（据《周易译注》总论提炼）
- 《归妹》以嫁出少女为义：男婚女嫁是人类蕃衍的根本（天地合而后万物兴，昏礼万世之始）。卦辞却“征凶，无攸利”：为所归之妹设诫：女子出嫁须严守正道，以柔顺为本成内助之功（含古代礼教对女子的约束）。
- 初安分卑居侧室（跛能履）、二嫁夫不良守贞（眇能视，利幽人之贞）、四愆期待时而嫁、五贵女谦逊下嫁（帝乙归妹，月几望吉）：合妇德故无凶；三“归妹以须”有非分之念（凶？），上“女承筐无实”处穷高之所无攸利。六五最纯吉。
- 广义：阴以阳为归宿则天地和合，万物繁殖；归妹，天地之大义也。天地不交而万物不兴。
**二体**：下兑上震；**互卦**：既济（二三四为下互，三四五为上互）

**六爻**
- 初九 归妹以娣，跛能履，征吉：以副手的身份嫁。→ 位置低但踏实，做好分内事，吉。
  - 小象：归妹以娣，以恒也；跛能履，吉相承也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“归妹以娣，跛能履，征吉”：配君子以广孕嗣成其家，像足虽偏而能履地而行。
- 九二 眇能视，利幽人之贞：眼睛不好但能看。→ 虽条件不理想，保持安静守正，利。
  - 小象：利幽人之贞，未变常也
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“眇能视，利幽人之贞”：美人香草之怨：幽人无贤君，正如九二无贤夫；守贞。
- 六三 归妹以须，反归以娣：等待而被退回。→ 位置不当会遭拒，别急，换位置/换方式再来。
  - 小象：归妹以须，未当也。
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“归妹以须，反归以娣”：“须”三说：荀陆作“孀”（妾）；须女（贱女）；面毛（须长可怖）；总之位不当，反嫁为娣。
- 九四 归妹愆期，迟归有时：延期出嫁。→ 慢一点没关系，等对的时候。
  - 小象：愆期之志，有待而行也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“归妹愆期，迟归有时”：愆期在我，不苟从人；有待而行，非为人所弃；“行”指出嫁。
- 六五 帝乙归妹，其君之袂不如其娣之袂良，月几望，吉：身份高却朴素。→ 地位高也要低调不奢华，吉。
  - 小象：帝乙归妹，不如其娣之袂良也；其位在中，以贵行也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）
  - 爻理：“帝乙归妹，其君之袂不如其娣之袂良，月几望，吉”：谦柔居中，以上下下；袂不如娣良：不崇饰；以贵行。
- 上六 女承筐无实，士刲羊无血，无攸利：无实的仪式。→ 空有形式没有实质，没有收获，别再坚持。
  - 小象：上六无实，承虚筐也。
  - 爻位：上阴、当位、与三爻无应（同性相敌）
  - 爻理：“女承筐无实，士刲羊无血，无攸利”：处穷极之位，妹居过高无所适从；日女日士，未成夫妇之辞；先女后士，咎在女。

**走向**：摆正名分则转渐；一意孤行则转睽。
