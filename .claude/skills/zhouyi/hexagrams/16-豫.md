# 第16卦 豫（震上坤下）· 顺势而动，喜悦欢乐，但需防沉溺

**卦辞**：利建侯行师。
**态势**：人心所向、气氛热烈，顺着民意/趋势做事容易成功；也最容易被喜悦麻痹而懈怠。
**像这样的事**：大家都支持的计划、团队士气高涨、项目预热成功、庆功或活动、被拥戴。
**判断要点**：① 众人情绪向着同一方向；② 你推出的事被广泛接受；③ 你自己也开始放松。
**对策**
- 宜：顺势立规、借势推动、预先做好制度与规划、以音乐般的节奏调动士气。
- 忌：沉迷享乐、得意忘形、没有准备就乘势出击、忽视潜在隐患。

**六爻**
- 初六 鸣豫，凶：自鸣得意。→ 太早炫耀成功会招祸，保持低调。
- 六二 介于石，不终日，贞吉：如石般清醒。→ 欢乐中保持明辨，不与不良风气同流。
- 六三 盱豫悔，迟有悔：仰着脸讨好权贵，又犹豫。→ 别用谄媚换机会，也别拖延，果断自立。
- 九四 由豫，大有得，勿疑朋盍簪：众人由你而乐。→ 你是核心，放心行动，信任伙伴，大有收获。
- 六五 贞疾，恒不死：长期有隐疾却不死。→ 压力与隐患存在，保持克制反而能长久。
- 上六 冥豫成，有渝无咎：沉迷已成。→ 若已沉溺，必须立刻转向、改变，否则祸不远。

**走向**：谨守则转随（顺随）；沉溺则转坎/困。
