# 第16卦 豫（震上坤下）· 顺势而动，喜悦欢乐，但需防沉溺

**卦辞**：利建侯行师。
**彖传**：豫，刚应而志行，顺以动，豫。豫，顺以动，故天地如之，而况建侯行师乎？天地以顺动，故日月不过，而四时不忒；圣人以顺动，则刑罚清而民服。豫之时义大矣哉！
**大象**：雷出地奋，豫；先王以作乐崇德，殷荐之上帝，以配祖考。
**态势**：人心所向、气氛热烈，顺着民意/趋势做事容易成功；也最容易被喜悦麻痹而懈怠。
**像这样的事**：大家都支持的计划、团队士气高涨、项目预热成功、庆功或活动、被拥戴。
**判断要点**：① 众人情绪向着同一方向；② 你推出的事被广泛接受；③ 你自己也开始放松。
**对策**
- 宜：顺势立规、借势推动、预先做好制度与规划、以音乐般的节奏调动士气。
- 忌：沉迷享乐、得意忘形、没有准备就乘势出击、忽视潜在隐患。

**卦理**（据《周易译注》总论提炼）
- 《豫》讲欢乐，两个要点：一要顺性而乐、适可而止（以顺动）；二要与物同乐、广乐天下（刚应而志行）。卦辞“利建侯行师”：顺天下之势而动，使天下同归安乐。《左传》：乐而不荒，乐以安民。
- 九四是全卦唯一阳爻，施乐者，群阴因之得豫；五阴是处乐者，吉凶不同：初过乐自鸣得意凶，三谄媚求乐有悔，五居尊不可耽乐须防疾，上昏冥纵乐不改有咎，唯六二中正不苟豫吉。处处诫人不可穷欢极乐（志不可满，乐不可极；生于忧患，死于安乐）。
- 忧乐互相依存；九四以广施欢乐为己任而大有得，近似“先天下之忧而忧，后天下之乐而乐”。
**二体**：下坤上震；**互卦**：蹇（二三四为下互，三四五为上互）；全卦仅一阳（四爻），常视为卦主

**六爻**
- 初六 鸣豫，凶：自鸣得意。→ 太早炫耀成功会招祸，保持低调。
  - 小象：初六鸣豫，志穷凶也。
  - 爻位：初阴、不当位、与四爻有应
  - 爻理：“鸣豫凶”：谦上六鸣谦吉，豫初六鸣豫凶——谦德可以有闻于外，欢乐之初不可得意忘形。
- 六二 介于石，不终日，贞吉：如石般清醒。→ 欢乐中保持明辨，不与不良风气同流。
  - 小象：不终日贞吉，以中正也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）
  - 爻理：中正，“介于石，不终日”：上交不谄，下交不渎，知几，不苟于乐，当机立断，贞吉。
- 六三 盱豫悔，迟有悔：仰着脸讨好权贵，又犹豫。→ 别用谄媚换机会，也别拖延，果断自立。
  - 小象：盱豫有悔，位不当也。
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“盱豫悔，迟有悔”：仰望谄媚求乐；与六二的速断对照：悔宜速，迟则又有悔（二中正，三不中正）。
- 九四 由豫，大有得，勿疑朋盍簪：众人由你而乐。→ 你是核心，放心行动，信任伙伴，大有收获。
  - 小象：由豫大有得，志大行也。
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“由豫，大有得，勿疑”：全卦唯一阳爻，众阴靠它而乐；居阴位、臣位、多惧之位，易疑，所以特戒“勿疑”（一阳若化则无阳）；盍簪：朋友聚合。
- 六五 贞疾，恒不死：长期有隐疾却不死。→ 压力与隐患存在，保持克制反而能长久。
  - 小象：六五贞疾，乘刚也；恒不死，中未亡也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“贞疾，恒不死”：居尊不可耽乐，被九四所乘如有疾而不死——法家拂士在侧，反而不得纵乐，所以能活；当豫而不为豫，以正自守。
- 上六 冥豫成，有渝无咎：沉迷已成。→ 若已沉溺，必须立刻转向、改变，否则祸不远。
  - 小象：冥豫在上，何可长也？
  - 爻位：上阴、当位、与三爻无应（同性相敌）
  - 爻理：“冥豫，成有渝，无咎”：昏冥于乐，勉其改变（渝）则无咎；与《升》上六“冥升”对照：开迁善之门。

**走向**：谨守则转随（顺随）；沉溺则转坎/困。
