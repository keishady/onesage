# 第1卦 乾（乾上乾下）· 纯阳刚健，主动开创

**卦辞**：元，亨，利，贞。
**态势**：你有实力、有势头，处在"该主动出击、自强不息"的阶段；但越强越要防过头。
**像这样的事**：创业起步、拿到资源要大干一场、被委以重任、自己是主导方、状态极好想乘势扩张。
**判断要点**：① 你是主动方，不是被动等待；② 条件基本具备，缺的是行动；③ 没有明显的强力对手压制你。
**对策**
- 宜：定大方向、亲自带头、持续精进、分阶段推进；保持刚健但守正。
- 忌：急躁冒进、独断专行、盛时不留余地、把"能做"当成"该做"。

**六爻**
- 初九 潜龙勿用：时机未到，能力在积累。→ 隐忍蓄力，不要急着亮相或下重注。
- 九二 见龙在田，利见大人：初露头角，可见贵人。→ 开始展示实力，主动找导师/合作方。
- 九三 君子终日乾乾，夕惕若，厉无咎：下卦之终，压力最大。→ 全力投入但时刻警惕，复盘、查漏、不松懈。
- 九四 或跃在渊，无咎：可进可退的临界点。→ 试探性跃进，留好退路，看准再动。
- 九五 飞龙在天，利见大人：权位、时机、能力俱佳。→ 放手做大事，凝聚人才，别骄。
- 上九 亢龙有悔：已到顶点，再进就过头。→ 收手、让利、交权、转守，不要硬撑。

**走向**：盛极则衰，要预设"下一步"。多爻变则易转为坤（需要从刚转柔、收敛）。
