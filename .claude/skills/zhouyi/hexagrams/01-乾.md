# 第1卦 乾（乾上乾下）· 纯阳刚健，主动开创

**卦辞**：元，亨，利，贞。
**彖传**：大哉乾元；万物资始，乃统天。云行雨施，品物流形。大明终始，六位时成，时乘六龙以御天。乾道变化，各正性命，保合太和，乃利贞。首出庶物，万国咸宁。
**大象**：天行健；君子以自强不息。
**态势**：你有实力、有势头，处在"该主动出击、自强不息"的阶段；但越强越要防过头。
**像这样的事**：创业起步、拿到资源要大干一场、被委以重任、自己是主导方、状态极好想乘势扩张。
**判断要点**：① 你是主动方，不是被动等待；② 条件基本具备，缺的是行动；③ 没有明显的强力对手压制你。
**对策**
- 宜：定大方向、亲自带头、持续精进、分阶段推进；保持刚健但守正。
- 忌：急躁冒进、独断专行、盛时不留余地、把"能做"当成"该做"。

**卦理**（据《周易译注》总论提炼）
- 卦象取“天”，不是说天本身，而是借天的刚健去比喻“阳刚”的气质；爻辞用“龙”也是同样的比喻。读爻辞要读它背后的义，不要拘泥字面（假象寓意，《易》的通例）。
- 六爻从“潜龙”写到“亢龙”，走完阳气萌生、增长、盛壮、穷尽的全过程：九五是最盛，上九是物极必反。
- 用九“见群龙无首”：越刚健越不要抢着当首领，刚而能柔。
**二体**：下乾上乾；**互卦**：乾（二三四为下互，三四五为上互）

**六爻**
- 初九 潜龙勿用：时机未到，能力在积累。→ 隐忍蓄力，不要急着亮相或下重注。
  - 小象：潜龙勿用，阳在下也
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：第一爻是发端，位低力弱，要蓄力。“勿用”是时机未到，不是永远不用，条件一到就要一步步推进。
- 九二 见龙在田，利见大人：初露头角，可见贵人。→ 开始展示实力，主动找导师/合作方。
  - 小象：见龙在田，德施普也
  - 爻位：二阳、不当位、居中、与五爻无应（同性相敌）
  - 爻理：阳刚渐长、初露头角；居中不偏，已具备成功的素质，所以称“大人”。
- 九三 君子终日乾乾，夕惕若，厉无咎：下卦之终，压力最大。→ 全力投入但时刻警惕，复盘、查漏、不松懈。
  - 小象：终日乾乾，反复道也
  - 爻位：三阳、当位、与上爻无应（同性相敌）
  - 爻理：这一爻称“君子”而不称龙：《易》按义取象，龙与君子都指刚强不息。三、四两爻处境最难（三在下卦之上、未入上卦），所谓“三多凶、四多惧”。
- 九四 或跃在渊，无咎：可进可退的临界点。→ 试探性跃进，留好退路，看准再动。
  - 小象：或跃在渊，进无咎也
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：已进上卦却居其下，上下都受压，处置不好最难受。所以“或跃在渊”：试探着进，同时留好退路。
- 九五 飞龙在天，利见大人：权位、时机、能力俱佳。→ 放手做大事，凝聚人才，别骄。
  - 小象：飞龙在天，大人造也
  - 爻位：五阳、当位、居中、与二爻无应（同性相敌）
  - 爻理：居上卦之中，多半是每卦最吉的一爻，象征事物发展到最圆满的阶段。
- 上九 亢龙有悔：已到顶点，再进就过头。→ 收手、让利、交权、转守，不要硬撑。
  - 小象：亢龙有悔，盈不可久也
  - 爻位：上阳、不当位、与三爻无应（同性相敌）
  - 爻理：盛极必衰，第六爻多讲这个道理。《易》的大义在于：越是盛满之时，越要设戒，想到“亢”。
- 用九 见群龙无首，吉：六爻皆动时用。→ 刚健到极处，不争做领头者、不以强压人，谦退反吉。
  - 小象：用九，天德不可为首也。
  - 爻理：越刚健、地位越高，越要不为物先；刚而能柔。

**走向**：盛极则衰，要预设"下一步"。多爻变则易转为坤（需要从刚转柔、收敛）。
