# 第39卦 蹇（坎上艮下）· 前有险阻，反身修德，联合求助

**卦辞**：利西南，不利东北。利见大人，贞吉。
**彖传**：蹇，难也，险在前也；见险而能止，知矣哉！蹇利西南，往得中也；不利东北，其道穷也。利见大人，往有功也；当位贞吉，以正邦也。蹇之时用大矣哉！
**大象**：山上有水，蹇；君子以反身修德。
**态势**：前方有险（水），后面有山，进退艰难；不要强闯，要停下来反省、整合力量、请贵人相助。
**像这样的事**：项目严重受阻、资源与环境双重困难、能力不足以过关、被困境逼迫要做取舍。
**判断要点**：① 障碍很实在；② 正面硬冲代价大；③ 找对帮手有机会化解。
**对策**
- 宜：反省自身不足、结交有力之人、选择平坦方向（西南）而非险处（东北）、守正、等时机。
- 忌：硬闯、怨天尤人、孤立无援地硬撑、放弃自我修养。

**卦理**（据《周易译注》总论提炼）
- 《蹇》是济蹇涉难。卦辞三义：一，进退合宜（利西南不利东北）；二，大人是济蹇主导（利见大人，聚合力量统一意志）；三，守持正固（贞吉）。
- 六爻：初六往蹇来誉（退处待时）；六二王臣蹇蹇匪躬之故（不计私利，尽心济难）；九三往蹇来反（暂退安内再求进）；六四往蹇来连（柔正前后皆险，自守）；九五大蹇朋来（大人济蹇，朋友来归）；上六往蹇来硕吉（附从贵君建大功）。至上爻才言吉：济蹇须长期艰苦。
- 大象“反身修德”；“见险而能止，知矣哉”。
**二体**：下艮上坎；**互卦**：未济（二三四为下互，三四五为上互）

**六爻**
- 初六 往蹇，来誉：往前遇难，回来得誉。→ 此时不要冒进，退回等待反而得到好评。
  - 小象：往蹇来誉，宜待也。
  - 爻位：初阴、不当位、与四爻无应（同性相敌）
  - 爻理：“往蹇，来誉”：来的意思是止于本位；初去险最远，其止最先，独具前识（智）。
- 六二 王臣蹇蹇，匪躬之故：为公事而艰难。→ 为了责任而受困，不是个人之过，要坚持。
  - 小象：王臣蹇蹇，终无尤也
  - 爻位：二阴、当位、居中、与五爻有应、承阳（托着上面的阳爻）
  - 爻理：“王臣蹇蹇，匪躬之故”：不言吉凶，只当鞠躬尽力，成败利钝非所论。二五是君臣相济，责不得辞。
- 九三 往蹇，来反：前进受阻，返回。→ 先回到内部，团结自己人，再出发。
  - 小象：往蹇来反，内喜之也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“往蹇，来反”：阳刚得正，坎险在前，先退后进；济蹇之术有多种，来而复反欲先安其内（内喜之）。
- 六四 往蹇，来连：往则遇难，来则联合。→ 与同伴联结，借助集体力量。
  - 小象：往蹇来连，当位实也。
  - 爻位：四阴、当位、与初爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“往蹇，来连”：来连有两说：还承五而连至尊（荀爽）；或连于九三合力以济（朱熹）。
- 九五 大蹇，朋来：大难中有朋来助。→ 越是大难，越要坚守中正，真正的朋友会来。
  - 小象：大蹇朋来，以中节也
  - 爻位：五阳、当位、居中、与二爻有应
  - 爻理：“大蹇，朋来”：诸爻皆不往，二、五君臣不往则蹇无由出，所以二曰蹇蹇、五曰大蹇；凡易之应莫重于二、五：五称“朋来”指二；在下占得五，念国事之艰难益致匪躬之节，在上占得二，谅臣子忠贞广朋来之助。
- 上六 往蹇，来硕，吉，利见大人：往则难，来则大有所获。→ 回头强化自己，去见大人（贵人），转为吉。
  - 小象：往蹇来硕，志在内也；利见大人，以从贵也。
  - 爻位：上阴、当位、与三爻有应、乘刚（压在阳爻上）
  - 爻理：“往蹇，来硕，吉，利见大人”：当位有应，附从贵君，济蹇之功必成；诸爻不言吉因未离蹇中，上六蹇极有可济之理。

**走向**：渡过则转解；一味硬闯则转坎。
