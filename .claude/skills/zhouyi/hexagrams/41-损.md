# 第41卦 损（艮上兑下）· 减损自己，以诚换长远

**卦辞**：有孚，元吉，无咎，可贞，利有攸往。曷之用？二簋可用享。
**彖传**：损，损下益上，其道上行。损而有孚，元吉无咎，可贞利有攸往。曷之用？二簋可用享。二簋应有时，损刚益柔有时。损益盈虚，与时偕行。
**大象**：山下有泽，损；君子以惩忿室欲。
**态势**：需要主动减少、让利、克制，换取更重要的东西；损下益上、损小益大，只要出于诚信，反而吉。
**像这样的事**：让利给伙伴、控制欲望与开支、精简业务、舍弃次要目标、必要的牺牲、断舍离。
**判断要点**：① 资源有限需取舍；② 你在为更大目标付出；③ 要分清"该损"与"不该损"。
**对策**
- 宜：诚心减损、简化、控制情绪与欲望、舍小取大、让利得人心。
- 忌：被迫的、怨怼的减损、损而无诚、损到伤根本、以损为名行不义。

**卦理**（据《周易译注》总论提炼）
- 《损》是损下益上。卦辞“有孚，元吉，无咎，可贞，利有攸往；曷之用？二簋可用享”：损道以诚信为本，微薄的二簋也足以奉献；损益盈虚，与时偕行：不可滥损、不可滥益、不合时则危（如取墙下土增墙上高，用非其时则墙危）。
- 下三爻自损、上三爻受益两两相对：初九酌损己刚应四（已事遄往）↔ 六四“损其疾，使遄有喜”；九二不自滥损、守正益上（利贞征凶，弗损益之）↔ 六五“十朋之龟”；六三三人行损一人、一人行得其友（专一）↔ 上九“得臣无家”。下卦损所当损，上卦四、五以阴居上虚己谦下受益，损中有益；上九受益广益于下，损益互相转化：自损者损极必获益，受益者益极当益人。
- 修身上：《大象》“惩忿窒欲”：自损不善；为学自损私欲以益公理，处世自损身家以益天下，是损道得其正而合于时中。
**二体**：下兑上艮；**互卦**：复（二三四为下互，三四五为上互）

**六爻**
- 初九 已事遄往，无咎，酌损之：做完自己的事赶紧去帮忙。→ 主动援助别人，但要量力而行。
  - 小象：已事遄往，尚合志也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“已事遄往，无咎，酌损之”：完事速往，损己奉上（学而优则仕）；酌情而损，不可过。
- 九二 利贞，征凶，弗损，益之：守正为利，躁进则凶。→ 不必牺牲原则去损己，守住自己反而是益他。
  - 小象：九二利贞，中以为志也
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“利贞，征凶，弗损益之”：自守不进似无益于上，实则启时君尊德乐道之心、止士大夫奔竞之习：“弗损”乃所以益之。
- 六三 三人行，则损一人；一人行，则得其友：人多则冲突。→ 合作宜精，三人太多，一人更专一，得其友。
  - 小象：一人行，三则疑也
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）
  - 爻理：“三人行则损一人，一人行则得其友”：专一之道（天地絪缊，男女构精）；不适合的益上，事实上是损上；损益盈虚与时偕行。
- 六四 损其疾，使遄有喜，无咎：减去毛病。→ 快速改掉缺点，有喜。
  - 小象：损其疾，亦可喜也
  - 爻位：四阴、当位、与初爻有应
  - 爻理：“损其疾，使遄有喜，无咎”：损相思之疾需初九阳刚来益；初九重在损己，六四重在受益。
- 六五 或益之十朋之龟，弗克违，元吉：有人送来大礼。→ 得人助益，不要推辞，大吉。
  - 小象：六五元吉，自上祐也。
  - 爻位：五阴、不当位、居中、与二爻有应、承阳（托着上面的阳爻）
  - 爻理：“或益之十朋之龟，弗克违，元吉”：虚中之德，自损人必益之；自上祐（《大有》上九“自天祐之”）。
- 上九 弗损，益之，无咎，贞吉，利有攸往，得臣无家：不用损，反而可益。→ 给别人好处，自己也得到更大的格局。
  - 小象：弗损益之，大得志也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“弗损益之，无咎，贞吉，利有攸往，得臣无家”：与九二“弗损益之”同而居位不同：二不自损而益上，上不自损而益下；因民之所利而利之，惠而不费。

**走向**：损而有信转益；损而无度转蹇/困。
