# 第51卦 震（震上震下）· 惊雷震动，临危不乱，因惧而修

**卦辞**：亨。震来虩虩，笑言哑哑。震惊百里，不丧匕鬯。
**彖传**：震，亨。震来虩虩，恐致福也。笑言哑哑，后有则也。震惊百里，惊远而惧迩也。出，可以守宗庙社稷，以为祭主也。
**大象**：洊雷，震；君子以恐惧修省。
**态势**：突发的冲击、惊吓、变故接连而来；虽然吓人，但保持镇定、借机修省，反而亨通。
**像这样的事**：突发危机、突然被质疑、意外变化、重大冲击、紧急事件、被吓到不知所措。
**判断要点**：① 事发突然；② 声势大而实际危害有限；③ 你能否稳住决定结果。
**对策**
- 宜：先稳住自己、保持礼仪与流程、借惊醒而修正、分清真危险与虚惊。
- 忌：惊慌失措、盲目跑动、失去仪式与规矩、被一时的声势吓退。

**卦理**（据《周易译注》总论提炼）
- 《震》取象雷动，震慑可致亨通：“战战栗栗，日谨一日；人莫蹶于山而蹶于垣”。卦辞：震来虩虩，笑言哑哑；震惊百里，不丧匕鬯：两层譬喻：慎行获福；君主教令震惊百里，社稷长保。大象“恐惧修省”：惶恐惊惧与修身省过的内在联系。
- 六爻：初九知惧致富（慎始）；六二因危守中，失贝复得；六三惶惶未安，慎行免祸；六五柔中危行，善保尊位；这四爻因惕惧修德多吉；九四陷于阴中惧而不能振奋，难以自拔（震遂泥）；上六惧极有凶，但若因邻之震预先戒备则无咎。处危而后安的辩证哲理。
**二体**：下震上震；**互卦**：蹇（二三四为下互，三四五为上互）

**六爻**
- 初九 震来虩虩，后笑言哑哑，吉：先惊后笑。→ 因恐惧而谨慎，终得吉。
  - 小象：震来虩虩，恐致福也；笑言哑哑，后有则也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“震来虩虩，后笑言哑哑，吉”：阳刚在下，慎始惧初，终得欢笑（范仲淹：惧于心则思虑慎其始，惧于身则进退不履危）。
- 六二 震来厉，亿丧贝，跻于九陵，勿逐，七日得：来势凶猛。→ 财物可能暂失，先退到高处，不追，会失而复得。
  - 小象：震来厉，乘刚也。
  - 爻位：二阴、当位、居中、与五爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“震来厉，亿丧贝，跻于九陵，勿逐，七日得”：乘刚而危，因危而惧，慎守柔中，不恋所失，终失而复得。
- 六三 震苏苏，震行无眚：震动恐惧。→ 因恐惧而行动调整，反而无灾。
  - 小象：震苏苏，位不当也
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、承阳（托着上面的阳爻）
  - 爻理：“震苏苏，震行无眚”：不乘刚又承阳，虽不当位却怀危惧慎行，终日惶恐修省，免灾；天下不患有忧惧之时，而患无修省之功。
- 九四 震遂泥：陷入泥里。→ 惊后行动滞涩，力量被卡，需要找回方向。
  - 小象：震遂泥，未光也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“震遂泥”：阳刚削弱，沉陷阴中，惊惶不能有为，坠落委颓；道德未光。
- 六五 震往来厉，亿无丧，有事：往来皆危。→ 虽然危险，持守中位、不丢失根本，仍有事可成。
  - 小象：震往来厉，危行也；其事在中，大无丧也。
  - 爻位：五阴、不当位、居中、与二爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“震往来厉，亿无丧，有事”：阴柔居尊处震，一举一动戒惧危厉，慎行中道；不失所有（不丧匕鬯，能主器以君天下）。
- 上六 震索索，视矍矍，征凶；震不于其躬，于其邻，无咎，婚媾有言：惊恐至极。→ 不要冲动出征，灾祸还在邻居身上，先做预防，会有小议论。
  - 小象：震索索，中未得也；虽凶无咎，畏邻戒也。
  - 爻位：上阴、当位、与三爻无应（同性相敌）
  - 爻理：“震索索，视矍矍，征凶；震不于其躬，于其邻，无咎，婚媾有言”：惧极有凶，但因邻之震预为修省则无咎；过于恐惧无取，睹事未然而知戒才被圣人所许。

**走向**：处震不惊转艮（静止、止）；惊乱则转豫失控。
