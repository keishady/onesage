# 第63卦 既济（坎上离下）· 大功告成，防止松懈与倒退

**卦辞**：亨，小利贞。初吉终乱。
**彖传**：既济，亨，小者亨也。利贞，刚柔正而位当也。初吉，柔得中也。终止则乱，其道穷也。
**大象**：水在火上，既济；君子以思患而豫防之。
**态势**：事情已经完成、秩序已定，一切各就其位；此时最大的风险是"成了"之后的懈怠与小问题。
**像这样的事**：项目交付、目标达成、产品上线、关系稳定、业绩达标、阶段性胜利后的维护。
**判断要点**：① 主要目标已实现；② 团队和心态开始松；③ 小隐患累积可能毁掉成果。
**对策**
- 宜：巩固成果、设立维护机制、居安思危、复盘总结、准备下一个目标。
- 忌：沾沾自喜、停滞不前、急着扩张、忽略细节、过度庆祝。

**卦理**（据《周易译注》总论提炼）
- 《既济》是事已成，但大旨是“守成艰难”：魏徵答太宗，创业不难、守成更难（志趣骄逸、徭役不休、侈务不息）。卦辞“亨小，利贞，初吉终乱”：事成之时亨通，但不可忘守正，稍不敬慎必复乱。
- 六爻无不见警戒：初“曳其轮，濡其尾”戒不可前、二“妇丧其茀，勿逐，七日得”、三“高宗伐鬼方三年克之，小人勿用”、四“繻有衣袽，终日戒”、五“东邻杀牛不如西邻之禴祭”（骄奢不修德）、上“濡其首，厉”。大象“君子以思患而豫防之”：处危则虑深，居安则意殆，患常生于怠忽。
**二体**：下离上坎；**互卦**：未济（二三四为下互，三四五为上互）

**六爻**
- 初九 曳其轮，濡其尾，无咎：拖着车轮，打湿尾巴。→ 起步要谨慎，慢慢来，别冲过头。
  - 小象：曳其轮，义无咎也。
  - 爻位：初阳、当位、与四爻有应
  - 爻理：“曳其轮，濡其尾，无咎”：事已成之始，阳刚居下谦谨稳重：刚得其正，不轻于动，守成无咎之道。
- 六二 妇丧其茀，勿逐，七日得：丢了遮蔽物。→ 暂时失去东西不必追，时间到了自然回来。
  - 小象：七日得，以中道也。
  - 爻位：二阴、当位、居中、与五爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“妇丧其茀，勿逐，七日得”：初吉，柔得中；失而不逐自得。
- 九三 高宗伐鬼方，三年克之，小人勿用：高宗伐鬼方，三年才胜。→ 大事花很长时间，别用小人。
  - 小象：三年克之，急也。
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“高宗伐鬼方，三年克之，小人勿用”：阳居阳位刚亢，正反设诫；恐其不能守初吉而致终乱。
- 六四 繻有衣袽，终日戒：船漏要备破布。→ 即使平稳也要防备，终日警惕。
  - 小象：终日戒，有所疑也。
  - 爻位：四阴、当位、与初爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“繻有衣袽，终日戒”：居多惧之地，上体坎险，过中生变，设戒尤切。
- 九五 东邻杀牛，不如西邻之禴祭，实受其福：重诚心不重形式。→ 不要铺张，真诚比排场更重要。
  - 小象：东邻杀牛，不如西邻之时也；实受其福，吉大来也。
  - 爻位：五阳、当位、居中、与二爻有应
  - 爻理：“东邻杀牛，不如西邻之禴祭，实受其福”：居盛时最忌骄奢不修道德；以东西邻为戒，以薄祭明德为勉（时也）。
- 上六 濡其首，厉：打湿了头。→ 事成之后仍冒进，会陷入危险，必须收手。
  - 小象：濡其首厉，何可久也！
  - 爻位：上阴、当位、与三爻有应、乘刚（压在阳爻上）
  - 爻理：“濡其首，厉”：不言凶而言厉，欲人知危惧而速改，则济犹可保。

**走向**：既济不守则转未济；守成则维持安定。
