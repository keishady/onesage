# 第63卦 既济（坎上离下）· 大功告成，防止松懈与倒退

**卦辞**：亨，小利贞。初吉终乱。
**彖传**：既济，亨，小者亨也。利贞，刚柔正而位当也。初吉，柔得中也。终止则乱，其道穷也。
**大象**：水在火上，既济；君子以思患而豫防之。
**态势**：事情已经完成、秩序已定，一切各就其位；此时最大的风险是"成了"之后的懈怠与小问题。
**像这样的事**：项目交付、目标达成、产品上线、关系稳定、业绩达标、阶段性胜利后的维护。
**判断要点**：① 主要目标已实现；② 团队和心态开始松；③ 小隐患累积可能毁掉成果。
**对策**
- 宜：巩固成果、设立维护机制、居安思危、复盘总结、准备下一个目标。
- 忌：沾沾自喜、停滞不前、急着扩张、忽略细节、过度庆祝。

**六爻**
- 初九 曳其轮，濡其尾，无咎：拖着车轮，打湿尾巴。→ 起步要谨慎，慢慢来，别冲过头。
  - 小象：曳其轮，义无咎也。
- 六二 妇丧其茀，勿逐，七日得：丢了遮蔽物。→ 暂时失去东西不必追，时间到了自然回来。
  - 小象：七日得，以中道也。
- 九三 高宗伐鬼方，三年克之，小人勿用：高宗伐鬼方，三年才胜。→ 大事花很长时间，别用小人。
  - 小象：三年克之，急也。
- 六四 繻有衣袽，终日戒：船漏要备破布。→ 即使平稳也要防备，终日警惕。
  - 小象：终日戒，有所疑也。
- 九五 东邻杀牛，不如西邻之禴祭，实受其福：重诚心不重形式。→ 不要铺张，真诚比排场更重要。
  - 小象：东邻杀牛，不如西邻之时也；实受其福，吉大来也。
- 上六 濡其首，厉：打湿了头。→ 事成之后仍冒进，会陷入危险，必须收手。
  - 小象：濡其首厉，何可久也！

**走向**：既济不守则转未济；守成则维持安定。
