# 第58卦 兑（兑上兑下）· 喜悦沟通，以诚悦人，防甜言

**卦辞**：亨，利贞。
**彖传**：兑，说也。刚中而柔外，说以利贞，是以顺乎天而应乎人。说以先民，民忘其劳；说以犯难，民忘其死：说之大，民劝矣哉！
**大象**：丽泽，兑；君子以朋友讲习。
**态势**：气氛愉快、沟通顺畅，人心悦服；但悦要建立在诚信和正道上，不能靠花言巧语。
**像这样的事**：谈判、营销、演讲、社交、教学、团队相处、说服。
**判断要点**：① 情绪愉悦、沟通活跃；② 容易被甜言蜜语打动；③ 要分清真诚与讨好。
**对策**
- 宜：诚恳沟通、讲道理且让人舒服、互相切磋、以悦服人而不是以利诱人。
- 忌：谄媚、过度迎合、被奉承冲昏头、只说不做、沉溺享乐。

**卦理**（据《周易译注》总论提炼）
- 《兑》是欣悦：强调“刚中柔外”为悦，刚为柔本、悦不失正。卦辞“亨，利贞”：欣悦可亨通，又须守正。孟子：理义之悦我心，犹刍豢之悦我口。
- 两阴爻皆以柔媚取悦，被否定（六三来兑凶、上六引兑）；四阳：初九和兑吉（刚正和悦，不比于柔）；九二孚兑吉悔亡（诚信）；九四商兑未宁，介疾有喜（商度抉择）；九五孚于剥有厉（居尊而悦信于小人）。阳刚不牵于阴柔，禀持正德，决绝邪谄，才成欣悦之至美；偏离正德曲为欣悦，不论是取悦于人还是因人而悦，皆致凶咎。《周易》所肯定的欣悦立足于道德准则。大象“朋友讲习”。
**二体**：下兑上兑；**互卦**：家人（二三四为下互，三四五为上互）

**六爻**
- 初九 和兑，吉：平和喜悦。→ 心态平和，与人和睦，吉。
  - 小象：和兑之吉，行未疑也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“和兑，吉”：居初体刚，和悦端正；爻位皆刚不比于柔，得说之正，和而不流。
- 九二 孚兑，吉，悔亡：诚信而悦。→ 以诚信相待，没有后悔。
  - 小象：孚兑之吉，信志也。
  - 爻位：二阳、不当位、居中、与五爻无应（同性相敌）
  - 爻理：“孚兑，吉，悔亡”：刚中，欣悦待人又中心信实；己以孚信为说，人不得妄说之。
- 六三 来兑，凶：主动讨好。→ 靠巴结别人求悦，凶，别失了尊严。
  - 小象：来兑之凶，位不当也。
  - 爻位：三阴、不当位、与上爻无应（同性相敌）、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“来兑，凶”：阴居阳位，求悦心切，谄邪求悦必凶。
- 九四 商兑未宁，介疾有喜：反复权衡。→ 在取舍间犹豫；心里知道对方谄媚不对，就坚决疏远、坚守正道，有喜。
  - 小象：九四之喜，有庆也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“商兑未宁，介疾有喜”：刚居柔，近比六三諛佞小人，心知其非而乐其柔媚，去取交战于胸；勉以介然疾恶小人则有喜。
- 九五 孚于剥，有厉：诚信被小人剥蚀。→ 对奉承者要警惕，避免被腐化。
  - 小象：孚于剥，位正当也！
  - 爻位：五阳、当位、居中、与二爻无应（同性相敌）
  - 爻理：“孚于剥，有厉”：所悦不当：说之感人最为可惧，感之者将以剥之；君子畏巧言令色。
- 上六 引兑：引诱他人。→ 以享乐引诱别人，不宜长久，退出这种局面。
  - 小象：上六引兑，未光也。
  - 爻位：上阴、当位、与三爻无应（同性相敌）、乘刚（压在阳爻上）
  - 爻理：“引兑”：三与上是兑之所以为兑：三在内卦曰“来”，上在外卦曰“引”；以言语引诱取悦。

**走向**：喜悦有度转节/涣；沉溺则转困。
