# 第49卦 革（兑上离下）· 变革除旧，时机成熟方可大变

**卦辞**：己日乃孚，元亨利贞，悔亡。
**彖传**：革，水火相息；二女同居，其志不相得，日革。己日乃孚，革而信之。文明以说，大亨以正，革而当，其悔乃亡。天地革而四时成，汤武革命，顺乎天而应乎人：革之时大矣哉！
**大象**：泽中有火，革；君子以治历明时。
**态势**：旧的体制/做法已走到尽头，必须改；但变革要等时机、取信于人、有清晰的方案，不能只靠一股气。
**像这样的事**：转型、换赛道、重组团队、换制度、人生重大改变、革新产品。
**判断要点**：① 旧办法确已失效；② 变革的条件与人心逐渐具备；③ 变革的方向清晰且正当。
**对策**
- 宜：先取信、再动手；充分论证、多次沟通（革言三就）；时机到了果断；以大势和民意为基。
- 忌：一时冲动、条件不成熟就硬变、变而无方案、只破不立。

**六爻**
- 初九 巩用黄牛之革：用黄牛皮捆牢。→ 现在还不能变，先稳固、不动。
  - 小象：巩用黄牛，不可以有为也。
- 六二 己日乃革之，征吉，无咎：时机到了才改。→ 等条件成熟后果断变革，吉。
  - 小象：己日革之，行有嘉也。
- 九三 征凶，贞厉，革言三就，有孚：多次讨论后才能动。→ 冲动必凶，反复论证、取得共识再动。
  - 小象：革言三就，又何之矣！
- 九四 悔亡，有孚改命，吉：悔恨消除，取信后改命。→ 人心已信，方向清晰，可大幅改变，吉。
  - 小象：改命之吉，信志也。
- 九五 大人虎变，未占有孚：大人如虎变，光明显著。→ 变革者气魄磅礴，成效可见，无需占问也获信任。
  - 小象：大人虎变，其文炳也。
- 上六 君子豹变，小人革面，征凶，居贞吉：君子豹变，小人变脸。→ 变革已基本完成，不要再追求彻底，巩固成果为上。
  - 小象：君子豹变，其文蔚也；小人革面，顺以从君也。

**走向**：变革成功转鼎（新秩序）；变革失败转睽/困。
