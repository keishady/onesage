# 第49卦 革（兑上离下）· 变革除旧，时机成熟方可大变

**卦辞**：己日乃孚，元亨利贞，悔亡。
**彖传**：革，水火相息；二女同居，其志不相得，日革。己日乃孚，革而信之。文明以说，大亨以正，革而当，其悔乃亡。天地革而四时成，汤武革命，顺乎天而应乎人：革之时大矣哉！
**大象**：泽中有火，革；君子以治历明时。
**态势**：旧的体制/做法已走到尽头，必须改；但变革要等时机、取信于人、有清晰的方案，不能只靠一股气。
**像这样的事**：转型、换赛道、重组团队、换制度、人生重大改变、革新产品。
**判断要点**：① 旧办法确已失效；② 变革的条件与人心逐渐具备；③ 变革的方向清晰且正当。
**对策**
- 宜：先取信、再动手；充分论证、多次沟通（革言三就）；时机到了果断；以大势和民意为基。
- 忌：一时冲动、条件不成熟就硬变、变而无方案、只破不立。

**卦理**（据《周易译注》总论提炼）
- 《革》是变革：朱熹“须彻底从新铸造一番”。成功的两大要素：一把握时机（己日乃孚：选定亟待转变的时候）；二存诚守正（有孚、元亨利贞、悔亡）。汤武革命，顺乎天而应乎人。
- 六爻展示变革全过程：初九“巩用黄牛之革”，阳微位卑，时未可变固守常制；六二“己日乃革之，征吉”，柔中有应，将变当断然行革；九三“革言三就”，小成，物情未安须慎抚人心，不可激进；九四“悔亡，有孚改命吉”，刚处柔，变局将著力改旧命；九五“大人虎变”，中正创制信德昭彰；上六“君子豹变，小人革面”，助成革命有功要安守成果，“征凶居贞吉”。始于固守旧规、终于安保新制：全面彻底的质变。
- 《周易》立足于“变”，《革》是论变的典型；可旁通到文学：刘勰“通变”、韩柳古文运动“惟陈言之务去”。大象“治历明时”。
**二体**：下离上兑；**互卦**：姤（二三四为下互，三四五为上互）

**六爻**
- 初九 巩用黄牛之革：用黄牛皮捆牢。→ 现在还不能变，先稳固、不动。
  - 小象：巩用黄牛，不可以有为也。
  - 爻位：初阳、当位、与四爻无应（同性相敌）
  - 爻理：“巩用黄牛之革”：力不胜革，时未可变，固守常制；与《遯》六二（欲遯不可遯）意相近：革初在下无应，当革而不可革。
- 六二 己日乃革之，征吉，无咎：时机到了才改。→ 等条件成熟后果断变革，吉。
  - 小象：己日革之，行有嘉也。
  - 爻位：二阴、当位、居中、与五爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“己日乃革之，征吉，无咎”：柔中有应，时值将变，配合阳刚尊者，革故除弊；行有嘉。
- 九三 征凶，贞厉，革言三就，有孚：多次讨论后才能动。→ 冲动必凶，反复论证、取得共识再动。
  - 小象：革言三就，又何之矣！
  - 爻位：三阳、当位、与上爻有应
  - 爻理：“征凶，贞厉，革言三就，有孚”：变革初成但物情未安，稍不慎则前功尽弃危及大局；革言三就：多次商议后才有信。
- 九四 悔亡，有孚改命，吉：悔恨消除，取信后改命。→ 人心已信，方向清晰，可大幅改变，吉。
  - 小象：改命之吉，信志也。
  - 爻位：四阳、不当位、与初爻无应（同性相敌）
  - 爻理：“悔亡，有孚改命，吉”：处上体之始，革道将大成。
- 九五 大人虎变，未占有孚：大人如虎变，光明显著。→ 变革者气魄磅礴，成效可见，无需占问也获信任。
  - 小象：大人虎变，其文炳也。
  - 爻位：五阳、当位、居中、与二爻有应
  - 爻理：“大人虎变，未占有孚”：中正居尊，既显德又见威，天下信从（虎变威德，望风而信）。
- 上六 君子豹变，小人革面，征凶，居贞吉：君子豹变，小人变脸。→ 变革已基本完成，不要再追求彻底，巩固成果为上。
  - 小象：君子豹变，其文蔚也；小人革面，顺以从君也。
  - 爻位：上阴、当位、与三爻有应、乘刚（压在阳爻上）
  - 爻理：“君子豹变，小人革面，征凶，居贞吉”：革已成之时，君子豹变：革命后佐命之勋皆得封拜；要安守成果，不再征。

**走向**：变革成功转鼎（新秩序）；变革失败转睽/困。
