# 第64卦 未济（离上坎下）· 尚未完成，谨慎收尾，开启新循环

**卦辞**：亨，小狐汔济，濡其尾，无攸利。
**彖传**：未济，亨，柔得中也。小狐汔济，未出中也。濡其尾无攸利，不续终也。虽不当位，刚柔应也。
**大象**：火在水上，未济；君子以慎辨物居方。
**态势**：事情看似快到了，却还没有真正完成；小狐过河到了岸边把尾巴弄湿，功亏一篑——最后一步最容易出错。
**像这样的事**：项目接近收尾、谈判临门一脚、转型尚未稳固、新阶段的开头、循环再开始。
**判断要点**：① 未完成但方向对；② 最后阶段需要慎重；③ 过去的经验可以作为下一轮起点。
**对策**
- 宜：谨慎收尾、分清轻重、看清局势再动、总结经验、小步前进、保持希望。
- 忌：急于收功、轻敌、骄躁、因差一点就放弃、重蹈覆辙。

**卦理**（据《周易译注》总论提炼）
- 《未济》居六十四卦之终：“易者，变也”的归结；序卦：物不可穷。事未成之时，若能审慎进取，未济之中必有可济之理。卦辞“亨，小狐汔济，濡其尾，无攸利”：努力求济可亨通，小狐将渡濡尾徒劳：不谨始慎终难成济。
- 下三爻（坎险）尚未能济，主于戒“慎”：初濡尾吝、二曳轮贞吉、三未济征凶（位不当，利涉大川）；上三爻（离明）已向既济转化，主于勉“行”：四贞吉悔亡、震用伐鬼方三年有赏于大国；五君子之光有孚吉；上有孚于饮酒无咎，濡其首有孚失是。上九尤深：虽转既济，若纵逸无度（饮酒濡首），必重返未济。成败随时可能转化：祸兮福之所倚。完美与成功是相对的，缺陷与未成时时伴随；设诫是最后的归宿；慎辨物居方。
**二体**：下坎上离；**互卦**：既济（二三四为下互，三四五为上互）

**六爻**
- 初六 濡其尾，吝：刚开始就湿尾。→ 缺乏准备就起步，尴尬，要提前评估。
  - 小象：濡其尾，亦不知极也。
  - 爻位：初阴、不当位、与四爻有应、承阳（托着上面的阳爻）
  - 爻理：“濡其尾，吝”：与《既济》初九濡尾无咎不同：既济阳刚得正知缓急不轻进，此才柔不正坎险之下未济之时冒险躁进，则濡尾不能济。
- 九二 曳其轮，贞吉：拖着车轮，控制节奏。→ 刹车稳住，保持节奏，吉。
  - 小象：九二贞吉，中以行正也。
  - 爻位：二阳、不当位、居中、与五爻有应
  - 爻理：“曳其轮，贞吉”：未济之时求济又处坎险，须审慎；与《既济》同戒，差一位因时不同。
- 六三 未济，征凶，利涉大川：没完成时硬冲不吉。→ 条件不足时别硬闯，但可借助有利条件过大险。
  - 小象：未济征凶，位不当也。
  - 爻位：三阴、不当位、与上爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“未济，征凶，利涉大川”：六爻皆位不当，唯六三特言“位不当”：才弱而处下体之上。
- 九四 贞吉，悔亡，震用伐鬼方，三年有赏于大国：坚持而行，终有赏。→ 守正且坚韧地攻坚，三年后有回报。
  - 小象：贞吉悔亡，志行也。
  - 爻位：四阳、不当位、与初爻有应
  - 爻理：“贞吉悔亡，震用伐鬼方，三年有赏于大国”：先自治而后治人（先言贞吉悔亡而后伐鬼方）。
- 六五 贞吉，无悔，君子之光，有孚，吉：君子光明。→ 以诚信与光明带人，成果显现，吉。
  - 小象：君子之光，其晖吉也。
  - 爻位：五阴、不当位、居中、与二爻有应、乘刚（压在阳爻上）、承阳（托着上面的阳爻）
  - 爻理：“贞吉无悔，君子之光，有孚，吉”：居上卦离日之中，君子之光，化未济为既济：光辉之盛如夏日、夜火。
- 上九 有孚于饮酒，无咎；濡其首，有孚失是：安心饮酒。→ 成功后可以放松，但沉溺就会失去判断。
  - 小象：饮酒濡首，亦不知节也。
  - 爻位：上阳、不当位、与三爻有应
  - 爻理：“有孚于饮酒，无咎；濡其首，有孚失是”：已从未济转为既济，若逸乐至极必再返未济；“无咎”含善补过，设诫之深；惧以终始，其要无咎。

**走向**：谨慎收尾则开启新循环，回到乾/屯；冒进则功败垂成。
