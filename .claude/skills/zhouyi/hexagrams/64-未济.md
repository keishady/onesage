# 第64卦 未济（离上坎下）· 尚未完成，谨慎收尾，开启新循环

**卦辞**：亨，小狐汔济，濡其尾，无攸利。
**态势**：事情看似快到了，却还没有真正完成；小狐过河到了岸边把尾巴弄湿，功亏一篑——最后一步最容易出错。
**像这样的事**：项目接近收尾、谈判临门一脚、转型尚未稳固、新阶段的开头、循环再开始。
**判断要点**：① 未完成但方向对；② 最后阶段需要慎重；③ 过去的经验可以作为下一轮起点。
**对策**
- 宜：谨慎收尾、分清轻重、看清局势再动、总结经验、小步前进、保持希望。
- 忌：急于收功、轻敌、骄躁、因差一点就放弃、重蹈覆辙。

**六爻**
- 初六 濡其尾，吝：刚开始就湿尾。→ 缺乏准备就起步，尴尬，要提前评估。
- 九二 曳其轮，贞吉：拖着车轮，控制节奏。→ 刹车稳住，保持节奏，吉。
- 六三 未济，征凶，利涉大川：没完成时硬冲不吉。→ 条件不足时别硬闯，但可借助有利条件过大险。
- 九四 贞吉，悔亡，震用伐鬼方，三年有赏于大国：坚持而行，终有赏。→ 守正且坚韧地攻坚，三年后有回报。
- 六五 贞吉，无悔，君子之光，有孚，吉：君子光明。→ 以诚信与光明带人，成果显现，吉。
- 上九 有孚于饮酒，无咎；濡其首，有孚失是：安心饮酒。→ 成功后可以放松，但沉溺就会失去判断。

**走向**：谨慎收尾则开启新循环，回到乾/屯；冒进则功败垂成。
