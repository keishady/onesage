# OneSage

Formerly OneSage.

OneSage is the public brand name for this project.

The internal Python package name remains:

```text
onesage
```

The CLI module remains:

```text
onesage.cli
```

The strategic source package remains:

```text
onesage/strategic/
```

This is a branding migration, not a Python package refactor.

## Naming Rules

Use `OneSage` when referring to:

- the public product
- GitHub project identity
- README and documentation brand
- strategic intelligence skill concept

Use `onesage` when referring to:

- Python imports
- package directory
- CLI module path
- database/runtime internals
- existing code paths

## Release Note

OneSage was formerly developed under the name OneSage.

The v0.1.0-alpha public release uses the OneSage brand while preserving the existing `onesage` package and CLI compatibility.
